Notes de la versió

Actualitzacions

Devia Desktop comprova noves versions contra el manifest públic d'este lloc: updates/latest.json. Pots consultar-lo manualment o integrar-lo en els teus propis scripts.

Requisits

  • Almenys un agent CLI de codificació instal·lat: Claude Code, OpenAI Codex, Gemini CLI, OpenCode, Cursor Agent, GitHub Copilot CLI, Grok, Pi, Kimi, Hermes, Qwen, Qoder o DeepSeek. Devia els detecta automàticament.
  • Git instal·lat (recomanat) per a l'estat del repositori, els diffs i els worktrees de la vista dividida.
  • Docker (opcional) per a l'orquestració de Docker Compose per projecte.
