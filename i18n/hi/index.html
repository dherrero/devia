Devia Desktop डाउनलोड करें दस्तावेज़ीकरण पढ़ें

  1. Agents और निष्पादन

    Claude Code, Codex, Gemini CLI, OpenCode, Cursor Agent, Copilot, Grok, Pi, Kimi, Hermes, Qwen, Qoder और DeepSeek के साथ काम करें, या ACP बोलने वाला अपना agent जोड़ें। सत्र के बीच में agent बदलें और plan, apply या apply-yolo चुनें।

  2. Context और memory

    सत्रों के बीच स्थायी memory, प्रोजेक्ट-वार इतिहास, और context, लागत व tokens एक नज़र में। अपना code graph agent को प्रोजेक्ट की संरचना देता है, और code mode आपके MCP servers पर केवल पढ़ने वाली scripts चलाता है।

  3. Method और योजना

    हर प्रोजेक्ट का एक kanban, जिसे agent खुद पढ़ता और अपडेट करता है, specs, tasks और dependencies के साथ। Devia Method काम को दिशा देता है, और इंटरैक्टिव कार्ड किसी भी agent के साथ सवाल पूछते हैं, plans की मंज़ूरी माँगते हैं या बदलावों की समीक्षा कराते हैं।

  4. Git और समीक्षा

    रिपॉज़िटरी की स्थिति, inline diffs और branch बदलना। diff की पंक्तियों पर टिप्पणी करें और उन्हें समीक्षा के रूप में agent को भेजें। चार तक agents समानांतर, हर एक अपने git worktree में अलग।

  5. Remote और प्लेटफ़ॉर्म

    Devia खुला रहने तक Telegram से अपने agents चलाएँ, फ़ाइलें भेजने के साथ। Windows, macOS और Linux पर इंटीग्रेटेड terminal, Docker Compose और अपने IDE में खोलने की सुविधा।

सब कुछ आपकी मशीन पर

  • आपके सत्र, memory, kanban और कॉन्फ़िगरेशन आपकी डिस्क (~/.devia-app/) में रहते हैं।
  • न कोई खाता, न Devia का कोई क्लाउड।
  • आपकी मशीन से केवल वही बाहर जाता है जो हर agent का CLI अपने प्रदाता को भेजता है।
