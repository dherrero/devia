डाउनलोड

नवीनतम संस्करण:

Windows

Windows 10/11 (x64) के लिए NSIS इंस्टॉलर। इंस्टॉलेशन डायरेक्टरी चुनने देता है।

.exe डाउनलोड करें

जल्द आ रहा है

अगर SmartScreen चेतावनी दिखाए, तो “More info → Run anyway” दबाएँ।

macOS

साइन और notarize की गई .dmg डिस्क इमेज। Devia को Applications में खींचें।

Apple Silicon (.dmg) Intel (.dmg)

जल्द आ रहा है

macOS 11 Big Sur या उससे नए के साथ संगत।

Linux

यूनिवर्सल AppImage या Debian/Ubuntu (x64) के लिए .deb पैकेज।

AppImage .deb

जल्द आ रहा है

AppImage: chmod +x से चलाने की अनुमति दें और उसे लॉन्च करें। केवल AppImage अपने आप अपडेट होता है।

रिलीज़ नोट्स

अपडेट

Devia Desktop नए संस्करणों की जाँच इस साइट के सार्वजनिक manifest से करता है: updates/latest.json। आप उसे हाथ से देख सकते हैं या अपनी scripts में जोड़ सकते हैं।

आवश्यकताएँ

  • कम से कम एक CLI coding agent इंस्टॉल हो: Claude Code, OpenAI Codex, Gemini CLI, OpenCode, Cursor Agent, GitHub Copilot CLI, Grok, Pi, Kimi, Hermes, Qwen, Qoder या DeepSeek। Devia उन्हें अपने आप पहचानता है।
  • Git इंस्टॉल हो (अनुशंसित), रिपॉज़िटरी की स्थिति, diffs और split view के worktrees के लिए।
  • Docker (वैकल्पिक), प्रोजेक्ट-वार Docker Compose ऑर्केस्ट्रेशन के लिए।
