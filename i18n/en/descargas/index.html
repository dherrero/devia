Release notes

Updates

Devia Desktop checks for new versions against this site’s public manifest: updates/latest.json. You can query it manually or plug it into your own scripts.

Requirements

  • At least one coding CLI agent installed: Claude Code, OpenAI Codex, Gemini CLI, OpenCode, Cursor Agent, GitHub Copilot CLI, Grok, Pi, Kimi, Hermes, Qwen, Qoder, or DeepSeek. Devia detects them automatically.
  • Git installed (recommended) for repository status, diffs, and split-view worktrees.
  • Docker (optional) for per-project Docker Compose orchestration.
