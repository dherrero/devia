Примечания к версии

Обновления

Devia Desktop проверяет новые версии по публичному манифесту этого сайта: updates/latest.json. Вы можете проверить его вручную или встроить в собственные скрипты.

Требования

  • Установленный хотя бы один CLI-агент для написания кода: Claude Code, OpenAI Codex, Gemini CLI, OpenCode, Cursor Agent, GitHub Copilot CLI, Grok, Pi, Kimi, Hermes, Qwen, Qoder или DeepSeek. Devia обнаруживает их автоматически.
  • Установленный Git (рекомендуется) для состояния репозитория, диффов и worktrees разделённого вида.
  • Docker (опционально) для оркестрации Docker Compose по проектам.
