ملاحظات الإصدار

التحديثات

يتحقق Devia Desktop من الإصدارات الجديدة مقابل البيان العام لهذا الموقع: updates/latest.json. يمكنك الاطلاع عليه يدويًا أو دمجه في سكربتاتك الخاصة.

المتطلبات

  • أداة CLI برمجية وكيلة واحدة على الأقل مثبّتة: Claude Code أو OpenAI Codex أو Gemini CLI أو OpenCode أو Cursor Agent أو GitHub Copilot CLI أو Grok أو Pi أو Kimi أو Hermes أو Qwen أو Qoder أو DeepSeek. يكتشفها Devia تلقائيًا.
  • Git مثبّت (موصى به) لحالة المستودع والفروق وworktrees العرض المقسّم.
  • Docker (اختياري) لإدارة Docker Compose لكل مشروع.
