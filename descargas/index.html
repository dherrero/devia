Actualizaciones

Devia Desktop comprueba nuevas versiones contra el manifiesto público de este sitio: updates/latest.json. Puedes consultarlo manualmente o integrarlo en tus propios scripts.

Requisitos

  • Al menos un agente CLI de codificación instalado: Claude Code, OpenAI Codex, Gemini CLI, OpenCode, Cursor Agent, GitHub Copilot CLI, Qwen, DeepSeek o Qoder. Devia los detecta automáticamente.
  • Git instalado (recomendado) para el estado del repositorio, los diffs y los worktrees de la vista dividida.
  • Docker (opcional) para la orquestación de Docker Compose por proyecto.
