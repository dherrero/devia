What does Devia Desktop do?

🤖 Multi-agent

Work with Claude Code, OpenAI Codex, Gemini CLI, OpenCode, Cursor Agent, GitHub Copilot CLI, Qwen, DeepSeek, or Qoder, and switch agents without switching tools. Devia detects your installed CLIs and configures each project so they just work — no manual setup needed.

💬 Visual chat over the agent

Streaming responses, markdown, expandable tool-call cards, a diff viewer, and image attachments for multimodal models.

🪟 Multi-project and multi-session

Per-project session history, an instruction queue, and a split view with up to 4 panels — each with its own independent session and git worktree — letting multiple agents work in parallel in a single window.

📋 Kanban with built-in SDD

A per-project board that the agent itself reads and updates via MCP (devia-kanban), with specs, tasks, dependencies, and a full spec-driven development workflow.

🧠 Persistent memory

Devia ships with its own cross-session memory (devia-memory), scoped personally and per project, which the agent queries and feeds automatically.

🌿 Built-in Git

Live repository status, a change viewer with inline comments for requesting agent reviews, and worktree support.

🔌 MCP server manager

Install, enable, and share MCP servers across agents; Devia injects the configuration in each CLI's native format.

✨ Skills and prompt packs

Discover and install skills (local or from GitHub) and define per-project system prompt packages.

📱 Remote control via Telegram

Launch runs, check status, and chat with the agent from Telegram, with optional mirroring of the desktop conversation.

🖥️ Terminal and shell

A per-project integrated terminal (real PTY), open-in-your-favorite-IDE support, and Docker Compose orchestration.

🎙️ Voice

Local transcription with Whisper — no audio is ever sent to any API.

🛡️ Snapshots and audit

Snapshots and rollback before destructive operations, plus an audit log of every tool-call with automatic rotation and retention.

Built to work locally

Devia Desktop runs on top of your projects and your CLIs, on your machine. Your sessions, memory, Kanban board, and configuration all live on your disk (~/.devia-app/). No accounts, no cloud, no telemetry: just install, choose your working folder, and start directing agents.

1 · Install

Download the installer for your platform and open it. No prior configuration required.

2 · Connect your agents

Devia detects the coding CLIs you already have installed (Claude Code, Codex, Gemini CLI…) and makes them ready to use.

3 · Direct

Open a project from your workspace and start chatting: the agent codes, you review diffs, approve changes, and queue up the next instructions.
