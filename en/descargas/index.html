Release notes

Updates

Devia Desktop checks for new versions against this site's public manifest: updates/latest.json. You can check it manually or integrate it into your own scripts.

Requirements

  • At least one coding CLI agent installed: Claude Code, OpenAI Codex, Gemini CLI, OpenCode, Cursor Agent, GitHub Copilot CLI, Qwen, DeepSeek, or Qoder. Devia detects them automatically.
  • Git installed (recommended) for repository status, diffs, and worktrees in the split view.
  • Docker (optional) for per-project Docker Compose orchestration.
