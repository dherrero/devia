Aggiornamenti

Devia Desktop verifica la disponibilità di nuove versioni tramite il manifesto pubblico di questo sito: updates/latest.json. Puoi consultarlo manualmente o integrarlo nei tuoi script.

Requisiti

  • Almeno un agente CLI di codifica installato: Claude Code, OpenAI Codex, Gemini CLI, OpenCode, Cursor Agent, GitHub Copilot CLI, Qwen, DeepSeek o Qoder. Devia li rileva automaticamente.
  • Git installato (consigliato) per lo stato del repository, i diff e i worktree della vista divisa.
  • Docker (opzionale) per l'orchestrazione di Docker Compose per progetto.
