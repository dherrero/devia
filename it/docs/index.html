Documentazione di Devia Desktop

Che cos'è Devia Desktop?

Devia Desktop è un'applicazione desktop per sviluppare software con agenti di IA. È un'interfaccia unificata per diverse CLI agentiche (Claude Code, Codex, Gemini CLI e altre) che trasforma il lavoro con gli agenti da terminale in un'esperienza visiva, organizzata e multi-progetto.

È open source (Apache-2.0): gratuita e con tutte le funzioni, disponibile per Windows, macOS e Linux. Tutto funziona in locale, sui tuoi progetti e sulle tue CLI; non richiede account né connessione ad alcun servizio di Devia.

Installazione

Windows

  1. Scarica il programma di installazione .exe dalla pagina dei download.
  2. Avvialo e scegli la directory di installazione (installazione per utente, senza permessi di amministratore).
  3. Se SmartScreen mostra un avviso, clicca su «Ulteriori informazioni → Esegui comunque».

macOS

  1. Scarica il file .dmg per la tua architettura (Apple Silicon o Intel).
  2. Aprilo e trascina Devia nella cartella Applicazioni.
  3. L'app è firmata e notarizzata da Apple: si apre senza passaggi aggiuntivi.

Linux

  1. AppImage: scaricalo, assegna i permessi con chmod +x Devia-*.AppImage e avvialo.
  2. Debian/Ubuntu: installa il pacchetto con sudo dpkg -i devia_*_amd64.deb.

Primi passi

  1. Scegli il tuo workspace. La prima volta che apri Devia, una finestra modale ti chiede la cartella radice in cui risiedono i tuoi progetti (ad esempio ~/repos). Devia elenca i progetti che contiene e ne rileva la tecnologia.
  2. Connetti un agente. Devia rileva le CLI agentiche installate sulla tua macchina e ti permette di scegliere l'agente attivo nelle Impostazioni. Ogni progetto viene configurato in modo che l'agente funzioni senza interventi manuali.
  3. Conversa. Apri un progetto e scrivi la tua prima istruzione nel compositore. Scegli la modalità di esecuzione: plan (solo pianifica), apply (applica con permessi) o apply-yolo (senza conferme), in base a quanta autonomia vuoi concedere.
  4. Rivedi. Ogni risposta arriva in streaming con markdown, le chiamate agli strumenti si espandono in schede e le modifiche dell'agente appaiono come diff inline.

Agenti compatibili

Devia guida le seguenti CLI di codifica e puoi passare dall'una all'altra senza uscire dall'app. Il livello di integrazione varia a seconda dell'agente:

AgenteIntegrazione
Claude CodeLa più completa: server MCP per esecuzione, schede dei sub-agenti nella chat e ripresa automatica dopo un limite d'uso.
OpenCodeIntegrazione dedicata.
PiIntegrazione dedicata.
Kimi y HermesTramite Agent Client Protocol (ACP). Il profilo di Kimi non è ancora verificato rispetto alla CLI reale.
Codex, Gemini CLI, Cursor Agent, GitHub Copilot CLI, Grok, Qwen, Qoder y DeepSeekIntegrazione generica sullo streaming di ciascuna CLI.
Il tuo agenteQualsiasi CLI che parli ACP può essere definita in agent-defs.json.

Quando si continua una sessione con un agente diverso da quello che l'ha avviata, Devia esegue un passaggio di contesto: inietta un riepilogo del lavoro (obiettivo, file toccati e ultimi scambi) nel primo turno del nuovo agente e inserisce un divisore nella chat. Il riepilogo generato dall'IA richiede Claude e ANTHROPIC_API_KEY.

Cosa può fare Devia

Agenti ed esecuzione

  • Modalità plan, apply e apply-yolo salvate per sessione. Come vengono applicate dipende dall'agente: in Codex, ad esempio, la modalità plan si basa sulle istruzioni del prompt.
  • Importa sessioni esistenti di Claude Code, Codex e Grok e continuale in Devia.
  • Con Claude Code, Devia riprende da sola la sessione dopo un limite d'uso, finché l'app resta aperta.
  • Contesto usato, costo, token e compattazioni di ogni sessione, calcolati in locale.
  • Coda di istruzioni per progetto: metti in coda prompt mentre l'agente lavora, riordinali con il trascinamento, metti in pausa e riprendi.
  • Le chiamate dei sub-agenti di Claude Code appaiono annidate nella chat.

Multi-progetto e vista divisa

  • Elenco, creazione (vuoto o da template) e clonazione di progetti; preferiti fissati nella barra laterale.
  • Cronologia delle sessioni per progetto che sopravvive ai riavvii.
  • Fino a 4 pannelli (2×2) nella stessa finestra, ciascuno con la propria sessione e il proprio agente che lavorano in parallelo.
  • Ogni pannello aggiuntivo lavora isolato nel proprio git worktree, così due agenti non toccano mai gli stessi file.

Contesto e memoria

  • Memoria persistente tra le sessioni (devia-memory), personale e per progetto, con riordinamento semantico opzionale. L'agente la consulta e la alimenta; tu la gestisci nelle Impostazioni.
  • Grafo del codice proprio (6 linguaggi) che gli agenti consultano via MCP, con una vista /graph per esplorarlo.
  • Code mode: l'agente scrive uno script TypeScript che viene eseguito in una sandbox sui server MCP che scegli e restituisce solo il risultato. In questa versione gli script possono solo leggere.

Metodo e pianificazione

  • Kanban per progetto con spec, task e dipendenze che l'agente legge e aggiorna via MCP (devia-kanban). Lo stato vive fuori dal repository.
  • Devia Method: un metodo di sviluppo proprio (skill e prompt di avvio) che Devia fornisce a tutti gli agenti, attivabile per progetto.
  • Schede interattive per qualsiasi agente: domande, approvazione di piani, revisione di modifiche, conferme e selezione. Solo su desktop.
  • Gestore di skill, locali o da GitHub, e di sub-agenti riutilizzabili che Devia sincronizza con ogni CLI.

Git e revisione

  • Stato del repository in tempo reale, visualizzatore di diff inline, selettore di branch e pull solo fast-forward.
  • Commenti per riga sul diff che vengono inviati all'agente come richiesta di revisione.
  • Istantanee con ripristino della configurazione di MCP, skill e sub-agenti prima di modificarla.
  • Commit, push e pull request li fa l'agente con i propri strumenti: Devia non li crea da sé.

Server MCP

  • Gestore di server Model Context Protocol con un catalogo iniziale: installa, attiva e prova i server. Devia scrive la configurazione nel formato nativo di 9 agenti.
  • Ogni server può essere offerto direttamente all'agente o tramite code mode.

Controllo remoto via Telegram

  • Avvia esecuzioni, cambia modalità o agente, controlla lo stato (branch, contesto usato, costo) e conversa con l'agente da Telegram.
  • Invio di allegati all'agente e ricezione dei file che genera. Mirroring opzionale della conversazione desktop.
  • Funziona solo mentre Devia è aperto e risponde a una sola chat autorizzata. Le schede interattive non vengono mostrate in Telegram: l'agente chiede in testo.

Terminale, voce e altro

  • Terminale integrato per progetto con PTY reale, e apertura del progetto in 10 IDE.
  • Orchestrazione di Docker Compose: deploy, down e log per progetto.
  • Allegati di qualsiasi tipo (fino a 50 MB per file) e archivio dei file generati dall'agente.
  • Dettatura vocale locale; oggi solo in spagnolo.
  • Registro di audit di ogni tool-call.
  • Aggiornamento automatico delle installazioni (su Linux, solo con AppImage).

Capacità e limiti

Un riepilogo onesto di ciò che Devia fa oggi e di ciò che non fa ancora, così sai cosa aspettarti.

Cosa fa

  • Guidare 13 CLI agentiche da una finestra, con modalità plan, apply e apply-yolo.
  • Vista divisa fino a 4 pannelli con git worktree isolati.
  • Kanban, memoria, grafo del codice e code mode accessibili all'agente via MCP.
  • Gestore di MCP, di skill e di sub-agenti.
  • Schede interattive per fare domande, approvare piani e rivedere modifiche.
  • Commenti di revisione per riga inviati all'agente.
  • Controllo remoto via Telegram, con invio di file.
  • Terminale, Docker Compose e apertura negli IDE.

Cosa fa in parte

  • Importare sessioni: solo da Claude Code, Codex e Grok.
  • Riprendere dopo un limite d'uso: solo Claude Code, e solo finché l'app resta aperta.
  • Schede dei sub-agenti nella chat: solo Claude Code.
  • Reiniettare la memoria quando l'agente compatta il proprio contesto: solo Claude e Pi.
  • Agenti propri: solo quelli che parlano ACP.
  • Dettatura vocale: solo in spagnolo, e il suo funzionamento nella versione pacchettizzata è ancora da verificare.
  • Interfaccia in 11 lingue: spagnolo e inglese sono complete; nelle altre possono esserci testi non tradotti.
  • Telegram: solo mentre Devia è aperto, con una sola chat autorizzata e senza schede interattive.

Cosa non fa ancora

  • Creare commit, fare push o aprire pull request dall'interfaccia.
  • Usare GitHub, GitLab, Linear o Jira come fonte di task.
  • Editor di file integrato: l'albero del progetto è di sola lettura e i file si aprono nel tuo IDE.
  • Un coordinatore che avvii e supervisioni più agenti lavoratori. Oggi il parallelismo è la vista divisa, guidata da te.
  • Automazioni pianificate o attivate da eventi.
  • Eseguire su server remoti via SSH, nel cloud o senza interfaccia grafica.
  • Un'app mobile nativa: il cellulare si usa tramite Telegram.
  • Un sistema di plugin per pannelli o temi di terze parti.
  • Controllo del computer, emulatori mobili o un browser integrato.

Configurazione e dati

Quasi tutte le informazioni di Devia risiedono sul tuo disco, sotto ~/.devia-app/ (su Windows, C:\Users\<tuo-utente>\.devia-app\):

PercorsoContenuto
devia-app.config.jsonConfigurazione: workspace, agente attivo, lingua… (i segreti, come il token di Telegram, vengono salvati cifrati)
sessions/<proyecto>/Cronologia delle chat per progetto
projects/<clave>/Dati per progetto: bacheca Kanban (kanban.json) e memoria (memory.json)
memory-global.jsonMemoria personale
mcp-servers.jsonServer MCP configurati
snapshots/Istantanee della configurazione prima di modificarla
worktrees/Git worktree dei pannelli aggiuntivi della vista divisa
attachments/File allegati nel compositore o tramite Telegram
outbox-archive/File generati dall'agente

Per fare il backup di Devia basta copiare quella cartella. Eliminarla riporta l'app allo stato iniziale. Il registro di audit delle tool-call viene salvato a parte, nella cartella dei dati utente dell'applicazione.

Aggiornamenti

Le versioni pubblicate vengono annunciate nel manifest pubblico di questo sito: updates/latest.json. Contiene l'ultima versione disponibile, la data di pubblicazione, le note e i link di download per piattaforma.

Le installazioni di Devia Desktop si aggiornano da sole dalle Release del repository (su Linux, solo con AppImage). Puoi anche consultare l'ultima versione a mano o dai tuoi script:

curl -s https://dherrero.github.io/devia/updates/latest.json | jq .version

Domande frequenti sull'app

Devia è gratuito?

Sì. Devia Desktop è open source (Apache-2.0), con tutte le funzioni, su tutte le piattaforme.

Mi serve un account o una connessione a qualche servizio di Devia?

No. Devia Desktop funziona in locale. Gli unici servizi esterni usati sono quelli delle CLI degli agenti che hai configurato tu.

Devia include gli agenti di IA?

No: Devia è l'interfaccia che li guida. Devi avere installata almeno una CLI agentica (Claude Code, Codex, Gemini CLI, OpenCode…) con le sue credenziali. Devia le rileva e si occupa del resto.

I miei dati escono dalla mia macchina?

Sessioni, memoria, kanban e configurazione risiedono in ~/.devia-app/. Anche la dettatura vocale viene eseguita in locale. L'unica cosa che viaggia è ciò che la CLI dell'agente che usi invia al proprio provider.

In quali lingue è disponibile?

Questo sito è in spagnolo, inglese, valenciano, francese, tedesco, italiano, portoghese, russo, cinese, hindi e arabo. L'app ha le stesse 11 lingue, ma solo spagnolo e inglese sono complete: nelle altre possono comparire testi non tradotti.

Posso controllarlo dal cellulare?

Sì, tramite Telegram, purché Devia sia aperto sul tuo computer. Non esiste un'app mobile nativa.

Come segnalo un problema?

Apri una segnalazione nel repository GitHub di Devia con i passaggi per riprodurlo e la tua piattaforma (Windows/macOS/Linux).
