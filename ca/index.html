Una app d'escriptori per a dirigir Claude Code, Codex, Gemini i més.

Descarregar Devia Desktop Llegir la documentació

  1. Agents i execució

    Treballa amb Claude Code, Codex, Gemini CLI, OpenCode, Cursor Agent, Copilot, Grok, Pi, Kimi, Hermes, Qwen, Qoder i DeepSeek, o afig el teu si parla ACP. Canvia d'agent a mitja sessió i tria entre plan, apply i apply-yolo.

  2. Context i memòria

    Memòria persistent entre sessions, historial per projecte, i context, cost i tokens a la vista. Un graf de codi propi dona a l'agent l'estructura del projecte, i code mode executa scripts de només lectura sobre els teus servidors MCP.

  3. Mètode i planificació

    Un kanban per projecte que el mateix agent llig i actualitza, amb specs, tasques i dependències. Devia Method guia el treball, i les targetes interactives et pregunten, demanen aprovar plans o revisar canvis, amb qualsevol agent.

  4. Git i revisió

    Estat del repositori, diffs en línia i canvi de branca. Comenta línies del diff i les envies a l'agent com a revisió. Fins a quatre agents a la vegada, cadascun aïllat en el seu propi git worktree.

  5. Remot i plataforma

    Dirigix els teus agents des de Telegram, amb enviament de fitxers, mentre Devia estiga obert. Terminal integrat, Docker Compose i obertura en el teu IDE, en Windows, macOS i Linux.

Tot en la teua màquina

  • Les teues sessions, memòria, kanban i configuració viuen en el teu disc (~/.devia-app/).
  • Sense comptes ni núvol de Devia.
  • L'únic que ix de la teua màquina és el que envia el CLI de cada agent al seu proveïdor.
