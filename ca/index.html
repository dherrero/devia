Què fa Devia Desktop?

🤖 Multi-agent

Treballa amb Claude Code, OpenAI Codex, Gemini CLI, OpenCode, Cursor Agent, GitHub Copilot CLI, Qwen, DeepSeek o Qoder, i canvia d'agent sense canviar de ferramenta. Devia detecta els CLIs instal·lats i configura cada projecte perquè funcionen sense ajustos manuals.

💬 Xat visual sobre l'agent

Streaming de respostes, markdown, crides a ferramentes desplegables, visor de diffs i adjunts d'imatges per a models multimodals.

🪟 Multiprojecte i multisessió

Historial de sessions per projecte, cua d'instruccions i vista dividida de fins a 4 panells amb sessió i git worktree independents per panell — diversos agents treballant en paral·lel en una sola finestra.

📋 Kanban amb SDD integrat

Tauler per projecte que el propi agent llig i actualitza via MCP (devia-kanban), amb specs, tasques, dependències i flux spec-driven development.

🧠 Memòria persistent

Devia inclou la seua pròpia memòria entre sessions (devia-memory), amb àmbit personal i per projecte, que l'agent consulta i alimenta automàticament.

🌿 Git integrat

Estat del repositori en viu, visor de canvis amb comentaris en línia per a demanar revisions a l'agent, i suport de worktrees.

🔌 Gestor de servidors MCP

Instal·la, activa i compartix servidors MCP entre agents; Devia injecta la configuració en el format natiu de cada CLI.

✨ Skills i prompt packs

Descobrix i instal·la skills (locals o des de GitHub) i definix paquets de prompt de sistema per projecte.

📱 Control remot per Telegram

Llança execucions, consulta l'estat i conversa amb l'agent des de Telegram, amb mirall opcional de la conversació d'escriptori.

🖥️ Terminal i shell

Terminal integrat per projecte (PTY real), obertura en el teu IDE favorit i orquestració de Docker Compose.

🎙️ Veu

Transcripció local amb Whisper, sense enviar àudio a cap API.

🛡️ Snapshots i auditoria

Instantànies i rollback abans d'operacions destructives, i registre d'auditoria de cada tool-call amb rotació i retenció automàtica.

Fet per a treballar en local

Devia Desktop funciona sobre els teus projectes i els teus CLIs, en la teua màquina. Les teues sessions, la teua memòria, el teu kanban i la teua configuració viuen en el teu disc (~/.devia-app/). Sense comptes, sense núvol i sense telemetria: instal·les, tries la teua carpeta de treball i comences a dirigir agents.

1 · Instal·la

Descarrega l'instal·lador de la teua plataforma i obri'l. No requerix configuració prèvia.

2 · Connecta els teus agents

Devia detecta els CLIs de codificació que ja tens instal·lats (Claude Code, Codex, Gemini CLI…) i els deixa llestos per a usar.

3 · Dirigix

Obri un projecte del teu workspace i conversa: l'agent programa, tu revises diffs, approves i encues les instruccions següents.
