تنزيل Devia Desktop قراءة التوثيق

  1. الوكلاء والتنفيذ

    اعمل مع Claude Code وCodex وGemini CLI وOpenCode وCursor Agent وCopilot وGrok وPi وKimi وHermes وQwen وQoder وDeepSeek، أو أضف وكيلك الخاص إن كان يدعم ACP. بدّل الوكيل في منتصف الجلسة، واختر بين plan وapply وapply-yolo.

  2. السياق والذاكرة

    ذاكرة دائمة بين الجلسات، وسجل لكل مشروع، مع السياق والتكلفة والرموز (tokens) أمامك دائمًا. يمنح رسم بياني للشيفرة الوكيلَ بنية المشروع، وينفّذ code mode سكربتات للقراءة فقط على خوادم MCP لديك.

  3. المنهجية والتخطيط

    لوحة kanban لكل مشروع يقرؤها الوكيل نفسه ويحدّثها، مع مواصفات ومهام وتبعيات. يوجّه Devia Method العمل، وتسألك البطاقات التفاعلية وتطلب الموافقة على الخطط أو مراجعة التغييرات، مع أي وكيل.

  4. Git والمراجعة

    حالة المستودع، وفروق مضمّنة، وتبديل الفروع. علّق على أسطر الفروق وأرسلها إلى الوكيل كمراجعة. حتى أربعة وكلاء بالتوازي، كلٌّ معزول في git worktree خاص به.

    • worktree 1
    • worktree 2
    • worktree 3
    • worktree 4

  5. التحكم عن بُعد والمنصات

    وجّه وكلاءك من Telegram مع إرسال الملفات، ما دام Devia مفتوحًا. طرفية مدمجة وDocker Compose وفتح المشروع في بيئة التطوير لديك، على Windows وmacOS وLinux.

كل شيء على جهازك

  • جلساتك وذاكرتك وkanban وإعداداتك محفوظة على قرصك (~/.devia-app/).
  • دون حسابات ودون سحابة من Devia.
  • الشيء الوحيد الذي يغادر جهازك هو ما ترسله واجهة CLI الخاصة بكل وكيل إلى مزوّدها.
