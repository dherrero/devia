تنزيل Devia Desktop قراءة التوثيق

ماذا يفعل Devia Desktop؟

🤖 متعدد الوكلاء

اعمل مع Claude Code أو OpenAI Codex أو Gemini CLI أو OpenCode أو Cursor Agent أو GitHub Copilot CLI أو Qwen أو DeepSeek أو Qoder، وانتقل بين الوكلاء دون الحاجة إلى تغيير أدواتك. تكتشف Devia واجهات CLI المثبّتة وتُعدّ كل مشروع ليعمل دون أي ضبط يدوي.

💬 محادثة مرئية مع الوكيل

بثّ مباشر للردود، ودعم markdown، وعرض استدعاءات الأدوات في بطاقات قابلة للتوسّع، ومعاينة الفروق (diffs)، وإرفاق الصور للنماذج متعددة الوسائط.

🪟 متعدد المشاريع والجلسات

سجل جلسات لكل مشروع، وقائمة تعليمات، وعرض مقسّم يصل إلى 4 أجزاء بجلسة وgit worktree مستقلة لكل جزء — عدة وكلاء تعمل بالتوازي في نافذة واحدة.

📋 Kanban مع SDD مدمج

لوحة Kanban لكل مشروع يقرأها الوكيل ويحدّثها عبر MCP (devia-kanban)، مع المواصفات والمهام والتبعيات وسير عمل spec-driven development.

🧠 ذاكرة دائمة

تتضمن Devia ذاكرة خاصة بها تمتد بين الجلسات (devia-memory) بنطاق شخصي ولكل مشروع، يستشيرها الوكيل ويُغذّيها تلقائيًا.

🌿 Git مدمج

حالة المستودع في الوقت الفعلي، ومعاينة التغييرات مع تعليقات مضمّنة لطلب المراجعة من الوكيل، ودعم الـ worktrees.

🔌 مدير خوادم MCP

ثبّت خوادم MCP وفعّلها وشاركها بين الوكلاء؛ تحقن Devia الإعداد بالصيغة الأصلية لكل CLI.

✨ Skills وحزم الـ prompt

اكتشف وثبّت skills (محلية أو من GitHub) وعرّف حزم prompt النظام لكل مشروع.

📱 تحكم عن بُعد عبر Telegram

أطلق تشغيلات واستعلم عن الحالة وتحادث مع الوكيل من Telegram، مع إمكانية عكس محادثة سطح المكتب اختياريًا.

🖥️ الطرفية والصدفة

طرفية مدمجة لكل مشروع (PTY حقيقية)، وفتح في بيئة التطوير المفضّلة لديك، وتنسيق Docker Compose.

🎙️ الصوت

نسخ صوتي محلي باستخدام Whisper دون إرسال الصوت إلى أي واجهة برمجية خارجية.

🛡️ لقطات ومراجعة الأعمال

لقطات فورية واسترجاع قبل العمليات الحساسة، وسجل مراجعة لكل استدعاء أداة مع تدوير وحفظ تلقائي.

مصمَّم للعمل المحلي

يعمل Devia Desktop على مشاريعك وواجهات CLI الخاصة بك، على جهازك. جلساتك وذاكرتك ولوحة Kanban وإعداداتك كلها محفوظة على قرصك (~/.devia-app/). بلا حسابات، بلا سحابة، بلا قياس عن بُعد: ثبّت التطبيق، اختر مجلد عملك وابدأ في إدارة الوكلاء.

1 · ثبّت

نزّل المثبّت المناسب لمنصّتك وافتحه. لا يتطلب أي إعداد مسبق.

2 · اربط وكلاءك

تكتشف Devia واجهات CLI للبرمجة المثبّتة لديك (Claude Code وCodex وGemini CLI…) وتجعلها جاهزة للاستخدام فورًا.

3 · أدِر

افتح مشروعًا من مساحة عملك وتحادث: الوكيل يبرمج، وأنت تراجع الفروق وتوافق وتضيف التعليمات التالية إلى القائمة.
