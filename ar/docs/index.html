توثيق Devia Desktop

ما هو Devia Desktop؟

Devia Desktop تطبيق سطح مكتب لتطوير البرمجيات باستخدام وكلاء الذكاء الاصطناعي. إنه واجهة موحّدة وسهلة الاستخدام تجمع أدوات CLI الوكيلة المتعددة (Claude Code وCodex وGemini CLI والمزيد) لتحوّل العمل مع الوكلاء في الطرفية إلى تجربة مرئية منظّمة تدعم مشاريع متعددة.

هو FreeWare: مجاني بكامل ميزاته، ومتاح لـ Windows وmacOS وLinux. يعمل كل شيء محليًا على مشاريعك وواجهات CLI الخاصة بك؛ لا يحتاج إلى حساب أو اتصال بأي خدمة خارجية.

التثبيت

Windows

  1. نزّل المثبّت .exe من صفحة التنزيلات.
  2. شغّله واختر مجلد التثبيت (تثبيت على مستوى المستخدم، لا يحتاج صلاحيات المسؤول).
  3. إذا أظهر SmartScreen تنبيهًا، انقر «مزيد من المعلومات ← تشغيل على أي حال».

macOS

  1. نزّل ملف .dmg المناسب لبنية معالجك (Apple Silicon أو Intel).
  2. افتحه واسحب Devia إلى مجلد التطبيقات.
  3. التطبيق موقّع ومعتمد من Apple: يفتح مباشرة دون خطوات إضافية.

Linux

  1. AppImage: نزّله ومنحه صلاحيات التشغيل بـ chmod +x Devia-*.AppImage ثم شغّله.
  2. Debian/Ubuntu: ثبّت الحزمة بـ sudo dpkg -i devia_*_amd64.deb.

البدء السريع

  1. اختر مساحة العمل. في أول مرة تفتح فيها Devia، تطلب منك نافذة منبثقة تحديد المجلد الجذر الذي تقع فيه مشاريعك (مثلًا ~/repos). تُدرج Devia المشاريع التي يحتويها وتكتشف التقنية المستخدمة في كل منها.
  2. اربط وكيلًا. تكتشف Devia واجهات CLI الوكيلة المثبّتة على جهازك وتتيح لك اختيار الوكيل النشط من الإعدادات. يُعدّ كل مشروع تلقائيًا ليعمل الوكيل دون أي ضبط يدوي.
  3. تحادث. افتح مشروعًا واكتب أول تعليماتك في صندوق الرسائل. اختر وضع التشغيل — plan (تخطيط فقط) أو apply (تطبيق بصلاحيات) أو apply-yolo (بلا تأكيدات) — حسب مستوى الاستقلالية الذي تريد منحه.
  4. راجع. تصل كل استجابة مباشرةً مع دعم markdown، وتُعرض استدعاءات الأدوات في بطاقات قابلة للتوسّع، وتظهر تغييرات الوكيل كفروق مضمّنة.

الميزات

تعدد المشاريع والجلسات

  • عرض المشاريع وإنشاؤها (فارغة أو من قالب) واستنساخها؛ وتثبيت المفضّلة في الشريط الجانبي.
  • سجل جلسات لكل مشروع يبقى بعد إعادة التشغيل؛ استمر في جلسة أو ابدأ جلسة جديدة بنقرة واحدة.
  • قائمة التعليمات: أضف طلبات إلى قائمة الانتظار أثناء انشغال الوكيل، وأعد ترتيبها بالسحب والإفلات، وأوقفها واستأنفها.

عرض مقسّم متعدد الجلسات

  • حتى 4 أجزاء (2×2) في نفس النافذة، كل منها بجلسته الخاصة ووكيله يعمل بالتوازي.
  • كل جزء إضافي يعمل معزولًا في git worktree خاص به (فرع جديد من الفرع الرئيسي) لضمان عدم تعارض الوكلاء على نفس الملفات.
  • تبقى الأجزاء وworktrees الخاصة بها بعد إعادة تشغيل التطبيق مع استعادة ملفات كل جلسة.

Kanban مع SDD مدمج

  • لوحة Kanban لكل مشروع مع المواصفات والمهام والتبعيات.
  • يقرأ الوكيل اللوحة ويحدّثها عبر MCP (devia-kanban): سير عمل spec-driven development من البداية إلى النهاية.
  • تعيش الحالة خارج المستودع في مجلد بيانات Devia.

الذاكرة الدائمة

  • ذاكرة خاصة بين الجلسات (devia-memory) بنطاق شخصي ولكل مشروع.
  • يستشيرها الوكيل ويُغذّيها تلقائيًا: تُسجَّل القرارات والأخطاء المحلولة والاكتشافات.
  • لوحة إدارة في الإعدادات: ابحث وثبّت وانسَ أو امسح الملاحظات.

Git مدمج

  • حالة المستودع في الوقت الفعلي في الشريط الجانبي.
  • معاينة التغييرات مع تعليقات مضمّنة: علّق على أسطر الفرق وأرسلها إلى الوكيل كطلب مراجعة.
  • دعم الـ worktrees واللقطات الفورية مع إمكانية الاسترجاع قبل العمليات الحساسة.

خوادم MCP والـ skills والـ prompts

  • مدير خوادم Model Context Protocol: ثبّت الخوادم وفعّلها واختبرها وشاركها بين الوكلاء؛ تحقن Devia الإعداد بالصيغة الأصلية لكل CLI.
  • اكتشف وثبّت skills محلية أو من GitHub.
  • حزم الـ prompt: مجموعات prompt النظام لكل مشروع.
  • مدير وكلاء فرعيين متعددي CLI قابلين لإعادة الاستخدام بين المشاريع.

التحكم عن بُعد عبر Telegram

  • أطلق تشغيلات واستعلم عن الحالة (الفرع والسياق المستخدم والتكلفة) وتحادث مع الوكيل من Telegram.
  • عكس اختياري لمحادثة سطح المكتب وإرسال المرفقات (صور ومستندات) إلى الوكيل.

الطرفية والصوت والمزيد

  • طرفية مدمجة لكل مشروع مع PTY حقيقية، وفتح المشروع في بيئة التطوير المفضّلة لديك.
  • تنسيق Docker Compose: نشر وإيقاف وعرض سجلات لكل مشروع.
  • نسخ صوتي محلي باستخدام Whisper — لا يغادر الصوت جهازك أبدًا.
  • إرفاق الصور بالسحب والإفلات للنماذج متعددة الوسائط.
  • متصفح ملفات المشروع في الريل الأيمن وأرشيف الملفات التي يُنشئها الوكيل (outbox).
  • سجل مراجعة لكل استدعاء أداة مع تدوير تلقائي وحفظ لمدة 30 يومًا.
  • 11 لغة (es, en, ca, fr, de, it, pt, ru, zh, hi, ar)، و8 لوحات ألوان Material 3، وحجم خط قابل للتعديل.

التحديثات

تُعلَن الإصدارات المنشورة في المانيفست العام لهذا الموقع: updates/latest.json. يتضمّن أحدث إصدار متاح وتاريخ نشره والملاحظات وروابط التنزيل لكل منصة.

تستشير Devia Desktop هذا المانيفست لإخطارك بتوفّر إصدار جديد. يمكنك أيضًا التحقق يدويًا أو من خلال سكريبتاتك الخاصة:

curl -s https://dherrero.github.io/devia/updates/latest.json | jq .version

الأسئلة الشائعة

هل Devia مجاني؟

نعم. Devia Desktop برنامج FreeWare بكامل ميزاته على جميع المنصات.

هل أحتاج إلى حساب أو اتصال بأي خدمة من Devia؟

لا. يعمل Devia Desktop بالكامل محليًا. الخدمات الخارجية الوحيدة المستخدمة هي تلك الخاصة بواجهات CLI للوكلاء التي تُعدّها بنفسك.

هل تتضمّن Devia وكلاء الذكاء الاصطناعي؟

لا: Devia هي الواجهة التي تُدير الوكلاء. تحتاج إلى تثبيت واجهة CLI وكيلة واحدة على الأقل (Claude Code أو Codex أو Gemini CLI أو OpenCode…) مع بيانات اعتمادها. تكتشفها Devia وتتولى الباقي.

هل تغادر بياناتي جهازي؟

لا. الجلسات والذاكرة ولوحة Kanban والإعدادات كلها محفوظة في ~/.devia-app/. يعمل النسخ الصوتي باستخدام Whisper محليًا أيضًا. الشيء الوحيد الذي ينتقل هو ما يُرسله وكيل CLI الذي تستخدمه إلى مزوّده الخاص.

ما اللغات المتاحة؟

الإسبانية والإنجليزية والفالنسية والفرنسية والألمانية والإيطالية والبرتغالية والروسية والصينية والهندية والعربية.
