التحديثات

تتحقق Devia Desktop من الإصدارات الجديدة عبر المانيفست العام لهذا الموقع: updates/latest.json. يمكنك الاطلاع عليه يدويًا أو دمجه في سكريبتاتك الخاصة.

المتطلبات

  • واجهة CLI وكيلة واحدة على الأقل مثبّتة: Claude Code أو OpenAI Codex أو Gemini CLI أو OpenCode أو Cursor Agent أو GitHub Copilot CLI أو Qwen أو DeepSeek أو Qoder. تكتشفها Devia تلقائيًا.
  • Git مثبّت (موصى به) لعرض حالة المستودع والفروق والـ worktrees في العرض المقسّم.
  • Docker (اختياري) لتنسيق Docker Compose لكل مشروع.
