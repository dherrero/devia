Documentation de Devia Desktop

Qu'est-ce que Devia Desktop ?

Devia Desktop est une application de bureau pour développer des logiciels avec des agents IA. C'est une interface unifiée et conviviale pour plusieurs outils CLI agentiques (Claude Code, Codex, Gemini CLI et plus encore) qui transforme le travail avec des agents en terminal en une expérience visuelle, organisée et multi-projets.

C'est un FreeWare : gratuit avec 100% des fonctionnalités, disponible pour Windows, macOS et Linux. Tout fonctionne en local, sur vos projets et vos CLI ; aucun compte ni connexion à un service externe n'est nécessaire.

Installation

Windows

  1. Téléchargez le programme d'installation .exe depuis la page de téléchargements.
  2. Exécutez-le et choisissez le répertoire d'installation (installation par utilisateur, sans droits administrateur).
  3. Si SmartScreen affiche un avertissement, cliquez sur « Plus d'informations → Exécuter quand même ».

macOS

  1. Téléchargez le .dmg correspondant à votre architecture (Apple Silicon ou Intel).
  2. Ouvrez-le et faites glisser Devia dans le dossier Applications.
  3. L'application est signée et notariée par Apple : elle s'ouvre sans étapes supplémentaires.

Linux

  1. AppImage : téléchargez-le, accordez les permissions avec chmod +x Devia-*.AppImage et lancez-le.
  2. Debian/Ubuntu : installez le paquet avec sudo dpkg -i devia_*_amd64.deb.

Premiers pas

  1. Choisissez votre workspace. Au premier lancement de Devia, une fenêtre modale vous demande le dossier racine où résident vos projets (par exemple ~/repos). Devia liste les projets qu'il contient et détecte leur technologie.
  2. Connectez un agent. Devia détecte les CLI agentiques installés sur votre machine et vous permet de choisir l'agent actif dans les Paramètres. Chaque projet est configuré pour que l'agent fonctionne sans réglages manuels.
  3. Conversez. Ouvrez un projet et saisissez votre première instruction dans le compositeur. Choisissez le mode d'exécution — plan (planifie uniquement), apply (applique avec permissions) ou apply-yolo (sans confirmations) — selon le degré d'autonomie que vous souhaitez accorder.
  4. Révisez. Chaque réponse arrive en streaming avec du markdown, les appels d'outils se déploient en cartes et les modifications de l'agent s'affichent sous forme de diffs en ligne.

Lorsqu'une session se poursuit avec un agent différent de celui qui l'a démarrée, Devia effectue un transfert de contexte automatique : il injecte un résumé du travail effectué (objectif, fichiers modifiés et derniers échanges) dans le premier tour du nouvel agent et ajoute un séparateur dans le chat.

Fonctionnalités

Multi-projets et sessions

  • Liste, création (vide ou depuis un modèle) et clonage de projets ; épinglage des favoris dans la barre latérale.
  • Historique des sessions par projet qui survit aux redémarrages ; reprenez ou réinitialisez une session en un clic.
  • File d'instructions : mettez en file des prompts pendant que l'agent est occupé, réordonnez par glisser-déposer, mettez en pause et reprenez.

Vue fractionnée multi-sessions

  • Jusqu'à 4 panneaux (2×2) dans la même fenêtre, chacun avec sa propre session et son agent travaillant en parallèle.
  • Chaque panneau supplémentaire travaille isolé dans son propre git worktree (nouvelle branche depuis la branche principale) pour que deux agents ne modifient jamais les mêmes fichiers.
  • Le fractionnement et ses worktrees survivent au redémarrage de l'application, restaurant les fichiers de chaque session.

Kanban avec SDD intégré

  • Tableau Kanban par projet avec specs, tâches et dépendances.
  • L'agent lui-même lit et met à jour le tableau via MCP (devia-kanban) : flux spec-driven development de bout en bout.
  • L'état réside en dehors du dépôt, dans le dossier de données de Devia.

Mémoire persistante

  • Mémoire propre entre sessions (devia-memory) à portée personnelle et par projet.
  • L'agent la consulte et l'alimente automatiquement : décisions, bugs résolus et découvertes sont enregistrés.
  • Panneau de gestion dans les Paramètres : recherchez, épinglez, oubliez ou effacez des observations.

Git intégré

  • État du dépôt en temps réel dans la barre latérale.
  • Visionneuse de modifications avec commentaires en ligne : annotez des lignes du diff et envoyez-les à l'agent comme demande de révision.
  • Prise en charge des worktrees et des snapshots avec rollback avant les opérations destructives.

Serveurs MCP, skills et prompts

  • Gestionnaire de serveurs Model Context Protocol : installez, activez, testez et partagez des serveurs entre agents ; Devia injecte la configuration dans le format natif de chaque CLI.
  • Découvrez et installez des skills locaux ou depuis GitHub.
  • Prompt packs : paquets de prompts système par projet.
  • Gestionnaire de sous-agents multi-CLI réutilisables entre projets.

Télécommande via Telegram

  • Lancez des exécutions, consultez l'état (branche, contexte utilisé, coût) et conversez avec l'agent depuis Telegram.
  • Mise en miroir optionnelle de la conversation bureau et envoi de pièces jointes (photos, documents) à l'agent.

Terminal, voix et plus

  • Terminal intégré par projet avec PTY réel, et ouverture du projet dans votre IDE favori.
  • Orchestration de Docker Compose : deploy, down et logs par projet.
  • Transcription vocale locale avec Whisper — l'audio ne quitte jamais votre machine.
  • Pièces jointes d'images par glisser-déposer pour les modèles multimodaux.
  • Explorateur de fichiers du projet dans le rail droit et archive des fichiers générés par l'agent (outbox).
  • Journal d'audit de chaque tool-call avec rotation et rétention de 30 jours.
  • 11 langues (es, en, ca, fr, de, it, pt, ru, zh, hi, ar), 8 palettes d'accent Material 3 et taille de police ajustable.

Configuration et données

Toutes les données de Devia résident sur votre disque, dans ~/.devia-app/ (sous Windows, C:\Users\<tu-usuario>\.devia-app\) :

CheminContenu
devia-app.config.jsonConfiguration : workspace, agent actif, thème, langue…
sessions/<projet>/Historique de chat par projet
projects/<clé>/kanban.jsonTableau Kanban du projet
memory-global.json · projects/<clé>/memory.jsonMémoire persistante (personnelle · par projet)
mcp-servers.jsonServeurs MCP configurés
outbox-archive/Fichiers générés par l'agent
attachments/Images jointes dans la saisie
audit.logJournal des tool-calls (JSONL avec rotation)

Pour sauvegarder votre Devia, il suffit de copier ce dossier. Le supprimer remet l'application dans son état initial.

Mises à jour

Les versions publiées sont annoncées dans le manifeste public de ce site : updates/latest.json. Il contient la dernière version disponible, la date de publication, les notes de version et les liens de téléchargement par plateforme.

Devia Desktop consulte ce manifeste pour vous avertir qu'une nouvelle version est disponible. Vous pouvez également le vérifier manuellement ou depuis vos scripts :

curl -s https://dherrero.github.io/devia/updates/latest.json | jq .version

Questions fréquentes

Devia est-il gratuit ?

Oui. Devia Desktop est FreeWare avec 100% des fonctionnalités, sur toutes les plateformes.

Ai-je besoin d'un compte ou d'une connexion à un service Devia ?

Non. Devia Desktop fonctionne entièrement en local. Les seuls services externes utilisés sont ceux des agents CLI que vous avez configurés.

Devia inclut-il les agents IA ?

Non : Devia est l'interface qui les pilote. Vous devez avoir installé au moins un CLI agentique (Claude Code, Codex, Gemini CLI, OpenCode…) avec ses identifiants. Devia les détecte et s'occupe du reste.

Mes données quittent-elles ma machine ?

Non. Sessions, mémoire, kanban et configuration résident dans ~/.devia-app/. La transcription vocale avec Whisper s'exécute également en local. Seules les données que le CLI agent que vous utilisez envoie à son propre fournisseur transitent en dehors.

Dans quelles langues est-il disponible ?

Espagnol, anglais, valencien, français, allemand, italien, portugais, russe, chinois, hindi et arabe.

Comment signaler un problème ?

Ouvrez un ticket dans le dépôt GitHub de Devia en indiquant les étapes pour le reproduire et votre plateforme (Windows/macOS/Linux).
