Notes de version

—

Mises à jour

Devia Desktop vérifie les nouvelles versions auprès du manifeste public de ce site : updates/latest.json. Vous pouvez le consulter manuellement ou l'intégrer dans vos propres scripts.

Prérequis

  • Au moins un agent CLI de codage installé : Claude Code, OpenAI Codex, Gemini CLI, OpenCode, Cursor Agent, GitHub Copilot CLI, Qwen, DeepSeek ou Qoder. Devia les détecte automatiquement.
  • Git installé (recommandé) pour l'état du dépôt, les diffs et les worktrees de la vue fractionnée.
  • Docker (optionnel) pour l'orchestration de Docker Compose par projet.
