  1. Agent 与执行

    可使用 Claude Code、Codex、Gemini CLI、OpenCode、Cursor Agent、Copilot、Grok、Pi、Kimi、Hermes、Qwen、Qoder 和 DeepSeek，也可添加支持 ACP 的自有 Agent。会话中途可切换 Agent，并在 plan、apply 和 apply-yolo 之间选择。

    • plan
    • apply
    • apply-yolo

  2. 上下文与记忆

    跨会话的持久化记忆、按项目保存的历史，上下文、费用和 token 一目了然。自有的代码图谱让 Agent 了解项目结构，code mode 则在您的 MCP 服务器上运行只读脚本。

    • devia-memory
    • devia-code-graph
    • devia-code-mode

  3. 方法与规划

    每个项目一个 kanban，由 Agent 自行读取并更新，包含 spec、任务和依赖关系。Devia Method 指引工作流程，交互卡片会向您提问、请您批准计划或审查变更，适用于任何 Agent。

    • backlog
    • todo
    • in_progress
    • done

  4. Git 与审查

    仓库状态、行内差异和分支切换。可对差异的行添加评论，并作为审查意见发送给 Agent。最多四个 Agent 并行，各自隔离在独立的 git worktree 中。

    • worktree 1
    • worktree 2
    • worktree 3
    • worktree 4

  5. 远程与平台

    通过 Telegram 指挥 Agent 并发送文件，前提是 Devia 保持打开。内置终端、Docker Compose，以及在 IDE 中打开项目，支持 Windows、macOS 和 Linux。

    • /status
    • /mode
    • /agent
    • /stop

一切都在您的机器上

  • 您的会话、记忆、kanban 和配置都保存在本地磁盘（~/.devia-app/）。
  • 无需账号，也没有 Devia 云服务。
  • 离开您机器的，只有各 Agent 的 CLI 发送给其服务提供商的内容。
