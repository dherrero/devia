Devia Desktop 能做什么？

🤖 多 Agent 支持

支持 Claude Code、OpenAI Codex、Gemini CLI、OpenCode、Cursor Agent、GitHub Copilot CLI、Qwen、DeepSeek 或 Qoder，无需切换工具即可随时切换 Agent。Devia 自动检测已安装的 CLI 并为每个项目完成配置，无需手动调整。

💬 可视化 Agent 对话

支持流式响应、markdown 渲染、可展开的工具调用卡片、差异查看器，以及为多模态模型提供的图片附件功能。

🪟 多项目与多会话

按项目保存会话历史、支持指令队列，以及最多 4 面板（2×2）的分屏视图——每个面板拥有独立的会话和 git worktree，多个 Agent 可在同一窗口中并行工作。

📋 内置 SDD 的 Kanban 看板

每个项目配备 Kanban 看板，Agent 通过 MCP（devia-kanban）读取并更新看板，支持 spec、任务、依赖关系和完整的 spec-driven development 工作流。

🧠 持久化记忆

Devia 内置跨会话记忆（devia-memory），支持个人和项目两种作用域，Agent 可自动查询和写入记忆。

🌿 Git 集成

实时显示仓库状态，支持带行内注释的变更查看器（可直接向 Agent 发起审查请求），以及 worktree 支持。

🔌 MCP 服务器管理器

安装、启用并在 Agent 间共享 MCP 服务器；Devia 会自动将配置注入每个 CLI 的原生格式。

✨ Skills 与 prompt packs

发现并安装 skills（本地或来自 GitHub），并为每个项目定义系统 prompt 包。

📱 Telegram 远程控制

通过 Telegram 发起任务、查询状态，并与 Agent 对话；可选开启桌面对话镜像功能。

🖥️ 终端与 Shell

每个项目配备真实 PTY 终端，支持在您喜爱的 IDE 中打开项目，以及 Docker Compose 编排。

🎙️ 语音输入

使用 Whisper 进行本地语音转录，音频不会发送至任何外部 API。

🛡️ 快照与审计

在破坏性操作前自动创建快照并支持回滚，同时记录每次工具调用的审计日志，自动轮转与保留。

专为本地开发而生

Devia Desktop 在您自己的机器上运行，基于您的项目和 CLI。您的会话、记忆、看板和配置均保存在本地磁盘（~/.devia-app/）。无需注册账号、无需云服务、无遥测数据：安装后选择工作目录，即可开始指挥 Agent。

1 · 安装

下载适合您平台的安装包并打开。无需任何前置配置。

2 · 连接 Agent

Devia 自动检测您已安装的编程 CLI（Claude Code、Codex、Gemini CLI……）并使其立即可用。

3 · 开始指挥

打开工作区中的项目并开始对话：Agent 编写代码，您审查差异、确认更改并将后续指令加入队列。
