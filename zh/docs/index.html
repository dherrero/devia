Devia Desktop 文档

什么是 Devia Desktop？

Devia Desktop 是一款专为 AI Agent 辅助软件开发打造的桌面应用。它是多款 CLI Agent 工具（Claude Code、Codex、Gemini CLI 等）的友好统一界面，将终端 Agent 工作流转化为可视化、有序的多项目开发体验。

它是 FreeWare：全功能免费，支持 Windows、macOS 和 Linux。一切均在本地运行，基于您自己的项目和 CLI；无需账号，无需连接任何外部服务。

安装

Windows

  1. 从下载页下载 .exe 安装包。
  2. 运行安装包并选择安装目录（按用户安装，无需管理员权限）。
  3. 如果 SmartScreen 显示警告，请点击「更多信息 → 仍要运行」。

macOS

  1. 下载适合您芯片架构的 .dmg（Apple Silicon 或 Intel）。
  2. 打开镜像文件，将 Devia 拖入 应用程序 文件夹。
  3. 应用已经过 Apple 签名与公证，可直接打开，无需额外步骤。

Linux

  1. AppImage：下载后使用 chmod +x Devia-*.AppImage 授予执行权限，然后直接运行。
  2. Debian/Ubuntu：使用 sudo dpkg -i devia_*_amd64.deb 安装软件包。

快速上手

  1. 选择工作区。首次打开 Devia 时，会弹出对话框请您选择项目根目录（例如 ~/repos）。Devia 将列出其中包含的项目并自动识别技术栈。
  2. 连接 Agent。Devia 检测您机器上已安装的 CLI Agent，并允许您在设置中选择当前使用的 Agent。每个项目将自动完成配置，无需手动调整。
  3. 开始对话。打开一个项目，在输入框中输入您的第一条指令。根据您希望赋予 Agent 的自主程度，选择执行模式——plan（仅规划）、apply（带权限确认执行）或 apply-yolo（无需确认直接执行）。
  4. 审查结果。每条响应以流式传输并渲染 markdown，工具调用以卡片形式展开，Agent 的代码变更以行内差异形式呈现。

功能特性

多项目与会话管理

  • 项目列表、创建（空白或从模板）与克隆；在侧边栏中固定常用项目。
  • 按项目保存的会话历史，重启后依然保留；一键继续或重新开始会话。
  • 指令队列：在 Agent 忙碌时排队输入 prompt，支持拖拽重排、暂停与恢复。

多会话分屏视图

  • 同一窗口最多支持 4 个面板（2×2），每个面板拥有独立会话，Agent 并行工作。
  • 每个附加面板均运行在独立的 git worktree 中（从主分支创建新分支），确保多个 Agent 不会互相干扰同一文件。
  • 分屏状态及其 worktree 在应用重启后自动恢复，保留每个会话的文件。

内置 SDD 的 Kanban 看板

  • 每个项目配备 Kanban 看板，支持 spec、任务和依赖关系管理。
  • Agent 通过 MCP（devia-kanban）直接读取和更新看板，实现端到端的 spec-driven development 工作流。
  • 看板状态存储于 Devia 数据目录，独立于代码仓库之外。

持久化记忆

  • 内置跨会话记忆（devia-memory），支持个人和项目两种作用域。
  • Agent 自动查询和写入记忆：决策、已解决的 bug 和重要发现均会被记录。
  • 设置中提供记忆管理面板：可搜索、置顶、遗忘或清除记忆条目。

Git 集成

  • 侧边栏实时显示仓库状态。
  • 带行内注释的变更查看器：在差异行上添加注释并发送给 Agent 请求审查。
  • 支持 worktree 和快照，可在破坏性操作前进行回滚。

MCP 服务器、Skills 与 Prompt

  • Model Context Protocol 服务器管理器：安装、启用、测试并在 Agent 间共享服务器；Devia 自动将配置注入每个 CLI 的原生格式。
  • 发现并安装本地或来自 GitHub 的 skills。
  • Prompt packs：为每个项目定义系统 prompt 包。
  • 可跨项目复用的多 CLI 子 Agent 管理器。

Telegram 远程控制

  • 通过 Telegram 发起任务、查询状态（分支、上下文用量、费用）并与 Agent 对话。
  • 可选开启桌面对话镜像功能，支持向 Agent 发送附件（图片、文档）。

终端、语音及更多

  • 每个项目配备真实 PTY 终端，支持在您喜爱的 IDE 中打开项目。
  • Docker Compose 编排：按项目执行 deploy、down 和日志查看。
  • 使用 Whisper 进行本地语音转录——音频始终留在您的机器上。
  • 支持拖拽图片附件，适用于多模态模型。
  • 右侧栏提供项目文件浏览器，以及 Agent 生成文件的归档（outbox）。
  • 每次工具调用的审计日志，保留期 30 天，自动轮转。
  • 11 种语言（es, en, ca, fr, de, it, pt, ru, zh, hi, ar）、8 种 Material 3 主题色和可调字体大小。

配置与数据

Devia 的所有数据均保存在本地磁盘，位于 ~/.devia-app/（Windows 下为 C:\Users\<tu-usuario>\.devia-app\）：

路径内容
devia-app.config.json配置：工作区、当前 Agent、主题、语言……
sessions/<proyecto>/按项目保存的对话历史
projects/<clave>/kanban.json项目 Kanban 看板
memory-global.json · projects/<clave>/memory.json持久化记忆（个人 · 按项目）
mcp-servers.json已配置的 MCP 服务器
outbox-archive/Agent 生成的文件
attachments/输入框中附加的图片
audit.log工具调用日志（JSONL 格式，自动轮转）

备份 Devia 只需复制该文件夹。删除该文件夹将使应用恢复到初始状态。

版本更新

已发布的版本将在本站的公开更新清单中公告：updates/latest.json。清单包含最新可用版本号、发布日期、更新说明及各平台下载链接。

Devia Desktop 会自动检查该清单并在有新版本时通知您。您也可以手动查询或在脚本中集成：

curl -s https://dherrero.github.io/devia/updates/latest.json | jq .version

常见问题

Devia 免费吗？

是的。Devia Desktop 是 FreeWare，在所有平台上提供 100% 完整功能，永久免费。

我需要注册账号或连接 Devia 的服务吗？

不需要。Devia Desktop 完全在本地运行。唯一会使用的外部服务是您自己配置的 CLI Agent 所属的服务。

Devia 包含 AI Agent 吗？

不包含：Devia 是指挥 Agent 的界面。您需要至少安装一个 CLI Agent（Claude Code、Codex、Gemini CLI、OpenCode……）并配置相应的凭证。Devia 会自动检测并处理其余一切。

我的数据会上传到云端吗？

不会。会话、记忆、看板和配置均保存在 ~/.devia-app/。Whisper 语音转录也在本地执行。唯一会传输的数据是您所使用的 CLI Agent 发送给其自身服务提供商的内容。

支持哪些语言？

西班牙语、英语、瓦伦西亚语、法语、德语、意大利语、葡萄牙语、俄语、中文、印地语和阿拉伯语。

如何反馈问题？

请在 Devia 的 GitHub 仓库中提交 Issue，并附上复现步骤及您的操作系统（Windows/macOS/Linux）。
