Devia Desktop 文档

什么是 Devia Desktop？

Devia Desktop 是一款用于借助 AI Agent 开发软件的桌面应用。它是多款 CLI Agent 工具（Claude Code、Codex、Gemini CLI 等）之上的统一界面，将终端中的 Agent 工作转化为可视化、有序的多项目体验。

它是开源软件（Apache-2.0）：免费且全部功能可用，支持 Windows、macOS 和 Linux。一切都在本地运行，基于您的项目和 CLI；无需账号，也无需连接任何 Devia 服务。

安装

Windows

  1. 从下载页下载 .exe 安装包。
  2. 运行安装包并选择安装目录（按用户安装，无需管理员权限）。
  3. 如果 SmartScreen 显示警告，请点击「更多信息 → 仍要运行」。

macOS

  1. 下载适合您芯片架构的 .dmg（Apple Silicon 或 Intel）。
  2. 打开后，将 Devia 拖入应用程序文件夹。
  3. 应用已由 Apple 签名并公证：无需额外步骤即可打开。

Linux

  1. AppImage：下载后使用 chmod +x Devia-*.AppImage 授予执行权限，然后运行。
  2. Debian/Ubuntu：使用 sudo dpkg -i devia_*_amd64.deb 安装软件包。

快速上手

  1. 选择工作区。首次打开 Devia 时，会弹出对话框请您选择存放项目的根目录（例如 ~/repos）。Devia 会列出其中的项目并识别其技术栈。
  2. 连接 Agent。Devia 会检测您机器上已安装的 CLI Agent，并让您在设置中选择当前使用的 Agent。每个项目都会完成配置，无需手动调整即可使用 Agent。
  3. 开始对话。打开一个项目，在输入框中输入您的第一条指令。选择执行模式：plan（仅规划）、apply（带权限确认执行）或 apply-yolo（无需确认），取决于您想赋予多大的自主权。
  4. 审查结果。每条响应以流式传输并渲染 markdown，工具调用以卡片形式展开，Agent 的变更以行内差异呈现。

支持的 Agent

Devia 可指挥以下编程 CLI，您可以在不离开应用的情况下在它们之间切换。集成程度因 Agent 而异：

Agent集成程度
Claude Code最完整：按次执行的 MCP 服务器、聊天中的子 Agent 卡片，以及达到使用限额后自动恢复。
OpenCode专用集成。
Pi专用集成。
Kimi 和 Hermes通过 Agent Client Protocol（ACP）。Kimi 的配置尚未针对真实 CLI 验证。
Codex、Gemini CLI、Cursor Agent、GitHub Copilot CLI、Grok、Qwen、Qoder 和 DeepSeek基于各 CLI 流式输出的通用集成。
您自己的 Agent任何支持 ACP 的 CLI 都可以在 agent-defs.json 中定义。

当您用与原始 Agent 不同的 Agent 继续会话时，Devia 会执行上下文交接：将工作摘要（目标、修改的文件和最近的交互）注入新 Agent 的第一轮对话，并在聊天中插入分隔线。由 AI 生成摘要需要 Claude 和 ANTHROPIC_API_KEY。

Devia 能做些什么

Agent 与执行

  • plan、apply 和 apply-yolo 模式按会话保存。具体如何生效取决于 Agent：例如在 Codex 中，plan 模式依赖提示词中的指令。
  • 导入 Claude Code、Codex 和 Grok 的现有会话，并在 Devia 中继续。
  • 使用 Claude Code 时，达到使用限额后 Devia 会自动恢复会话，前提是应用保持打开。
  • 每个会话已用的上下文、费用、token 和压缩次数，均在本地计算。
  • 按项目的指令队列：Agent 工作时可排队输入 prompt，通过拖放重新排序，也可暂停和恢复。
  • Claude Code 子 Agent 的调用会嵌套显示在聊天中。

多项目与分屏视图

  • 项目列表、创建（空白或从模板）与克隆；常用项目固定在侧边栏。
  • 按项目保存的会话历史，重启后依然保留。
  • 同一窗口最多 4 个面板（2×2），每个面板拥有自己的会话，Agent 并行工作。
  • 每个附加面板都隔离运行在自己的 git worktree 中，因此两个 Agent 永远不会修改同一批文件。

上下文与记忆

  • 跨会话的持久化记忆（devia-memory），分为个人和按项目两种，可选语义重排序。Agent 会查询并写入记忆；您在设置中管理。
  • 自有的代码图谱（6 种语言），Agent 通过 MCP 查询，并提供 /graph 视图用于浏览。
  • Code mode：Agent 编写一个 TypeScript 脚本，在沙箱中针对您选择的 MCP 服务器运行，只返回结果。当前版本中脚本只能读取。

方法与规划

  • 每个项目一个 kanban，包含 spec、任务和依赖关系，Agent 通过 MCP（devia-kanban）读取并更新。其状态保存在仓库之外。
  • Devia Method：Devia 自有的开发方法（skills 和启动 prompt），提供给所有 Agent，可按项目启用。
  • 适用于任何 Agent 的交互卡片：提问、批准计划、审查变更、确认和选择。仅限桌面端。
  • skills 管理器（本地或来自 GitHub）和可复用子 Agent 管理器，Devia 会将它们同步到各个 CLI。

Git 与审查

  • 实时仓库状态、行内差异查看器、分支选择器，以及仅限 fast-forward 的 pull。
  • 对差异按行添加评论，并作为审查请求发送给 Agent。
  • 在修改 MCP、skills 和子 Agent 配置之前创建快照，并支持恢复。
  • commit、push 和 pull request 由 Agent 使用其自身工具完成：Devia 本身不会创建它们。

MCP 服务器

  • Model Context Protocol 服务器管理器，附带初始目录：安装、启用并测试服务器。Devia 会以 9 种 Agent 的原生格式写入配置。
  • 每个服务器既可以直接提供给 Agent，也可以通过 code mode 提供。

Telegram 远程控制

  • 通过 Telegram 发起任务、切换模式或 Agent、查询状态（分支、已用上下文、费用）并与 Agent 对话。
  • 可向 Agent 发送附件并接收其生成的文件。可选开启桌面对话镜像。
  • 仅在 Devia 保持打开时可用，且只服务一个已授权的聊天。交互卡片不会在 Telegram 中显示：Agent 会以文字提问。

终端、语音及更多

  • 按项目的集成终端，使用真实 PTY，并可在 10 种 IDE 中打开项目。
  • Docker Compose 编排：按项目执行 deploy、down 和查看日志。
  • 支持任意类型的附件（每个文件最大 50 MB），并归档 Agent 生成的文件。
  • 本地语音听写；目前仅支持西班牙语。
  • 每次 tool-call 的审计日志。
  • 安装版本自动更新（在 Linux 上仅限 AppImage）。

能力与限制

坦诚概述 Devia 目前能做什么、还不能做什么，让您心中有数。

已具备

  • 在一个窗口中指挥 13 个 CLI Agent，支持 plan、apply 和 apply-yolo 模式。
  • 最多 4 个面板的分屏视图，使用相互隔离的 git worktree。
  • Agent 可通过 MCP 使用 kanban、记忆、代码图谱和 code mode。
  • MCP、skills 和子 Agent 管理器。
  • 用于提问、批准计划和审查变更的交互卡片。
  • 按行的审查评论，并发送给 Agent。
  • 通过 Telegram 远程控制，并可发送文件。
  • 终端、Docker Compose 以及在 IDE 中打开项目。

部分具备

  • 导入会话：仅限来自 Claude Code、Codex 和 Grok 的会话。
  • 达到使用限额后恢复：仅限 Claude Code，且仅在应用保持打开时。
  • 聊天中的子 Agent 卡片：仅限 Claude Code。
  • Agent 压缩上下文时重新注入记忆：仅限 Claude 和 Pi。
  • 自有 Agent：仅限支持 ACP 的 Agent。
  • 语音听写：仅支持西班牙语，其在打包版本中的运行情况有待验证。
  • 界面支持 11 种语言：西班牙语和英语已完整；其余语言中可能存在未翻译的文本。
  • Telegram：仅在 Devia 保持打开时可用，只有一个已授权的聊天，且没有交互卡片。

尚不具备

  • 在界面中创建 commit、执行 push 或打开 pull request。
  • 将 GitHub、GitLab、Linear 或 Jira 用作任务来源。
  • 内置文件编辑器：项目树为只读，文件在您的 IDE 中打开。
  • 能启动并监督多个工作 Agent 的协调者。目前的并行方式是由您主导的分屏视图。
  • 定时或由事件触发的自动化。
  • 通过 SSH、在云端或无图形界面地在远程服务器上运行。
  • 原生移动应用：手机端通过 Telegram 使用。
  • 用于第三方面板或主题的插件系统。
  • 控制电脑、移动模拟器或内置浏览器。

配置与数据

Devia 的几乎所有数据都保存在您的磁盘上，位于 ~/.devia-app/（Windows 下为 C:\Users\<tu-usuario>\.devia-app\）：

路径内容
devia-app.config.json配置：工作区、当前 Agent、语言……（机密信息，如 Telegram 令牌，以加密方式保存）
sessions/<proyecto>/按项目保存的聊天历史
projects/<clave>/按项目的数据：Kanban 看板（kanban.json）和记忆（memory.json）
memory-global.json个人记忆
mcp-servers.json已配置的 MCP 服务器
snapshots/修改前的配置快照
worktrees/分屏视图中附加面板的 git worktree
attachments/在输入框中或通过 Telegram 添加的文件
outbox-archive/Agent 生成的文件

备份 Devia 只需复制该文件夹。删除它会使应用恢复到初始状态。tool-call 的审计日志单独保存在应用的用户数据文件夹中。

版本更新

已发布的版本会在本站的公开清单中公告：updates/latest.json。其中包含最新可用版本、发布日期、更新说明以及各平台的下载链接。

Devia Desktop 的安装版本会通过仓库的 Releases 自动更新（在 Linux 上仅限 AppImage）。您也可以手动或在脚本中查询最新版本：

curl -s https://dherrero.github.io/devia/updates/latest.json | jq .version

关于 Devia 的常见问题

Devia 免费吗？

是的。Devia Desktop 是开源软件（Apache-2.0），在所有平台上提供全部功能。

我需要账号或连接 Devia 的服务吗？

不需要。Devia Desktop 在本地运行。使用的外部服务只有您自己配置的 CLI Agent 所属的服务。

Devia 包含 AI Agent 吗？

不包含：Devia 是指挥 Agent 的界面。您需要至少安装一个 CLI Agent（Claude Code、Codex、Gemini CLI、OpenCode……）并配置好相应凭证。Devia 会检测它们并处理其余事务。

我的数据会离开我的机器吗？

会话、记忆、kanban 和配置都保存在 ~/.devia-app/。语音听写同样在本地运行。唯一会传出的，是您所用 Agent 的 CLI 发送给其自身服务提供商的内容。

支持哪些语言？

本网站提供西班牙语、英语、瓦伦西亚语、法语、德语、意大利语、葡萄牙语、俄语、中文、印地语和阿拉伯语版本。应用拥有相同的 11 种语言，但只有西班牙语和英语是完整的：其他语言中可能出现未翻译的文本。

我可以用手机控制它吗？

可以，通过 Telegram，前提是 Devia 在您的电脑上保持打开。目前没有原生移动应用。

如何反馈问题？

请在 Devia 的 GitHub 仓库中提交 issue，并附上复现步骤和您的平台（Windows/macOS/Linux）。
