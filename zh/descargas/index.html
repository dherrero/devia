版本更新

Devia Desktop 通过本站公开的更新清单检查新版本：updates/latest.json。您可以手动查询，也可以将其集成到您自己的脚本中。

系统要求

  • 至少安装一个编程 CLI Agent：Claude Code、OpenAI Codex、Gemini CLI、OpenCode、Cursor Agent、GitHub Copilot CLI、Qwen、DeepSeek 或 Qoder。Devia 会自动检测。
  • 建议安装 Git，以支持仓库状态显示、差异查看和分屏视图的 worktree 功能。
  • Docker（可选），用于按项目进行 Docker Compose 编排。
