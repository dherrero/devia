Что умеет Devia Desktop?

🤖 Мульти-агент

Работайте с Claude Code, OpenAI Codex, Gemini CLI, OpenCode, Cursor Agent, GitHub Copilot CLI, Qwen, DeepSeek или Qoder и переключайтесь между агентами, не меняя инструмент. Devia обнаруживает установленные CLI и настраивает каждый проект так, чтобы они работали без ручной настройки.

💬 Визуальный чат поверх агента

Потоковая передача ответов, markdown, раскрываемые вызовы инструментов, просмотр диффов и прикрепление изображений для мультимодальных моделей.

🪟 Мультипроект и мультисессия

История сессий по проектам, очередь инструкций и разделённый вид до 4 панелей с независимыми сессией и git worktree в каждой — несколько агентов работают параллельно в одном окне.

📋 Kanban со встроенным SDD

Доска для каждого проекта, которую сам агент читает и обновляет через MCP (devia-kanban), со спецификациями, задачами, зависимостями и процессом spec-driven development.

🧠 Постоянная память

Devia включает собственную память между сессиями (devia-memory) с личной областью видимости и областью видимости проекта — агент обращается к ней и пополняет её автоматически.

🌿 Встроенный Git

Состояние репозитория в реальном времени, просмотр изменений с построчными комментариями для запроса ревью у агента и поддержка worktrees.

🔌 Менеджер MCP-серверов

Устанавливайте, включайте и используйте MCP-серверы совместно между агентами; Devia внедряет конфигурацию в нативный формат каждого CLI.

✨ Skills и prompt packs

Находите и устанавливайте skills (локально или из GitHub) и задавайте наборы системных промптов для каждого проекта.

📱 Удалённое управление через Telegram

Запускайте задачи, проверяйте статус и общайтесь с агентом из Telegram с опциональным зеркалированием десктопного разговора.

🖥️ Терминал и shell

Встроенный терминал для каждого проекта (настоящий PTY), открытие в вашей любимой IDE и оркестрация Docker Compose.

🎙️ Голос

Локальная транскрипция с Whisper — аудио не отправляется ни в какие API.

🛡️ Снимки состояния и аудит

Мгновенные снимки и откат перед деструктивными операциями, а также журнал аудита каждого tool-call с автоматической ротацией и хранением.

Создано для локальной работы

Devia Desktop работает с вашими проектами и вашими CLI прямо на вашей машине. Ваши сессии, память, kanban и конфигурация хранятся на вашем диске (~/.devia-app/). Без учётных записей, без облака, без телеметрии: установите, выберите рабочую папку — и начинайте управлять агентами.

1 · Установите

Скачайте установщик для вашей платформы и запустите его. Предварительная настройка не требуется.

2 · Подключите агентов

Devia обнаружит уже установленные на вашем компьютере CLI-инструменты (Claude Code, Codex, Gemini CLI…) и подготовит их к работе.

3 · Управляйте

Откройте проект из вашего workspace и начните общение: агент пишет код, вы просматриваете диффы, принимаете изменения и ставите в очередь следующие инструкции.
