Обновления

Devia Desktop проверяет наличие новых версий по публичному манифесту этого сайта: updates/latest.json. Вы можете проверить его вручную или интегрировать в собственные скрипты.

Системные требования

  • Хотя бы один установленный агентный CLI для написания кода: Claude Code, OpenAI Codex, Gemini CLI, OpenCode, Cursor Agent, GitHub Copilot CLI, Qwen, DeepSeek или Qoder. Devia обнаруживает их автоматически.
  • Git (рекомендуется) для отображения состояния репозитория, диффов и worktrees в режиме разделённого вида.
  • Docker (опционально) для оркестрации Docker Compose по проектам.
