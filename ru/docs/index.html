Документация Devia Desktop

Что такое Devia Desktop?

Devia Desktop: это десктопное приложение для разработки программного обеспечения с ИИ-агентами. Это единый интерфейс над несколькими агентными CLI-инструментами (Claude Code, Codex, Gemini CLI и другими), который превращает работу с агентами в терминале в визуальный, организованный и многопроектный опыт.

Это открытое ПО (Apache-2.0): бесплатно и со всеми функциями, доступно для Windows, macOS и Linux. Всё работает локально, с вашими проектами и вашими CLI; учётная запись и подключение к какому-либо сервису Devia не требуются.

Установка

Windows

  1. Скачайте установщик .exe со страницы загрузок.
  2. Запустите его и выберите папку для установки (установка для пользователя, без прав администратора).
  3. Если SmartScreen покажет предупреждение, нажмите «Подробнее → Выполнить в любом случае».

macOS

  1. Скачайте .dmg для вашей архитектуры (Apple Silicon или Intel).
  2. Откройте его и перетащите Devia в папку Программы.
  3. Приложение подписано и нотаризовано Apple: открывается без дополнительных шагов.

Linux

  1. AppImage: скачайте, дайте права на выполнение командой chmod +x Devia-*.AppImage и запустите.
  2. Debian/Ubuntu: установите пакет командой sudo dpkg -i devia_*_amd64.deb.

Первые шаги

  1. Выберите workspace. При первом запуске Devia модальное окно запросит корневую папку, в которой находятся ваши проекты (например ~/repos). Devia выведет список содержащихся в ней проектов и определит их технологию.
  2. Подключите агента. Devia обнаружит агентные CLI, установленные на вашей машине, и позволит выбрать активного агента в Настройках. Каждый проект будет настроен так, чтобы агент работал без ручной конфигурации.
  3. Общайтесь. Откройте проект и введите первую инструкцию в поле ввода. Выберите режим выполнения: plan (только планирует), apply (применяет с запросом разрешений) или apply-yolo (без подтверждений), в зависимости от того, сколько автономии вы хотите дать.
  4. Проверяйте. Каждый ответ приходит потоком с markdown, вызовы инструментов раскрываются в карточках, а изменения агента отображаются как инлайн-диффы.

Поддерживаемые агенты

Devia управляет следующими CLI для написания кода, и вы можете переключаться между ними, не выходя из приложения. Уровень интеграции зависит от агента:

АгентИнтеграция
Claude CodeСамая полная: MCP-серверы для каждого запуска, карточки суб-агентов в чате и автоматическое возобновление после лимита использования.
OpenCodeОтдельная интеграция.
PiОтдельная интеграция.
Kimi и HermesЧерез Agent Client Protocol (ACP). Профиль Kimi ещё не проверен на реальном CLI.
Codex, Gemini CLI, Cursor Agent, GitHub Copilot CLI, Grok, Qwen, Qoder и DeepSeekУниверсальная интеграция поверх потокового вывода каждого CLI.
Ваш собственный агентЛюбой CLI, поддерживающий ACP, можно описать в agent-defs.json.

При продолжении сессии с агентом, отличным от того, который её начал, Devia выполняет передачу контекста: в первый ход нового агента внедряется сводка работы (цель, затронутые файлы и последние обмены), а в чате появляется разделитель. Сводка, созданная ИИ, требует Claude и ANTHROPIC_API_KEY.

Что умеет Devia Desktop

Агенты и выполнение

  • Режимы plan, apply и apply-yolo сохраняются для каждой сессии. Как они применяются, зависит от агента: например, в Codex режим plan опирается на инструкции в промпте.
  • Импортируйте существующие сессии Claude Code, Codex и Grok и продолжайте их в Devia.
  • С Claude Code Devia сам возобновляет сессию после лимита использования, пока приложение остаётся открытым.
  • Использованный контекст, стоимость, токены и компактификации каждой сессии, рассчитанные локально.
  • Очередь инструкций для каждого проекта: добавляйте промпты, пока агент работает, переупорядочивайте перетаскиванием, ставьте на паузу и возобновляйте.
  • Вызовы суб-агентов Claude Code отображаются в чате вложенными.

Мультипроект и разделённый вид

  • Список, создание (пустого или из шаблона) и клонирование проектов; избранное закрепляется на боковой панели.
  • История сессий по проектам, сохраняющаяся после перезапусков.
  • До 4 панелей (2×2) в одном окне, каждая со своей сессией и агентом, работающим параллельно.
  • Каждая дополнительная панель работает изолированно в собственном git worktree, чтобы два агента никогда не меняли одни и те же файлы.

Контекст и память

  • Постоянная память между сессиями (devia-memory), личная и для проекта, с опциональным семантическим переранжированием. Агент обращается к ней и пополняет её; вы управляете ею в Настройках.
  • Собственный граф кода (6 языков), к которому агенты обращаются через MCP, с представлением /graph для его изучения.
  • Code mode: агент пишет скрипт на TypeScript, который выполняется в песочнице поверх выбранных вами MCP-серверов и возвращает только результат. В этой версии скрипты только читают.

Метод и планирование

  • Kanban для каждого проекта со спецификациями, задачами и зависимостями, которые агент читает и обновляет через MCP (devia-kanban). Состояние хранится за пределами репозитория.
  • Devia Method: собственный метод разработки (skills и стартовый промпт), который Devia передаёт всем агентам и который можно включить для каждого проекта.
  • Интерактивные карточки для любого агента: вопросы, утверждение планов, проверка изменений, подтверждения и выбор. Только на десктопе.
  • Менеджер skills, локальных или из GitHub, и повторно используемых суб-агентов, которые Devia синхронизирует с каждым CLI.

Git и ревью

  • Состояние репозитория в реальном времени, просмотр инлайн-диффов, выбор веток и pull только fast-forward.
  • Построчные комментарии к диффу, которые отправляются агенту как запрос на ревью.
  • Снимки состояния с восстановлением конфигурации MCP, skills и суб-агентов перед её изменением.
  • Коммиты, push и pull request делает агент своими инструментами: сам Devia их не создаёт.

MCP-серверы

  • Менеджер серверов Model Context Protocol с начальным каталогом: устанавливайте, включайте и тестируйте серверы. Devia записывает конфигурацию в нативном формате 9 агентов.
  • Каждый сервер можно предоставить агенту напрямую или через code mode.

Удалённое управление через Telegram

  • Запускайте выполнения, меняйте режим или агента, проверяйте статус (ветка, использованный контекст, стоимость) и общайтесь с агентом из Telegram.
  • Отправка вложений агенту и получение файлов, которые он создаёт. Опциональное зеркалирование десктопного разговора.
  • Работает только пока Devia открыт и обслуживает один авторизованный чат. Интерактивные карточки в Telegram не отображаются: агент спрашивает текстом.

Терминал, голос и многое другое

  • Встроенный терминал для каждого проекта с настоящим PTY и открытие проекта в 10 IDE.
  • Оркестрация Docker Compose: deploy, down и логи для каждого проекта.
  • Вложения любого типа (до 50 МБ на файл) и архив файлов, которые создаёт агент.
  • Локальная голосовая диктовка; сейчас только на испанском.
  • Журнал аудита каждого tool-call.
  • Автоматическое обновление установок (на Linux только для AppImage).

Возможности и ограничения

Честный обзор того, что Devia делает сегодня и чего пока не делает, чтобы вы знали, чего ожидать.

Что умеет

  • Управлять 13 агентными CLI из одного окна, в режимах plan, apply и apply-yolo.
  • Разделённый вид до 4 панелей с изолированными git worktree.
  • Kanban, память, граф кода и code mode, доступные агенту через MCP.
  • Менеджер MCP, skills и суб-агентов.
  • Интерактивные карточки для вопросов, утверждения планов и проверки изменений.
  • Построчные комментарии ревью, отправляемые агенту.
  • Удалённое управление через Telegram с отправкой файлов.
  • Терминал, Docker Compose и открытие в IDE.

Что умеет частично

  • Импорт сессий: только из Claude Code, Codex и Grok.
  • Возобновление после лимита использования: только Claude Code и только пока приложение открыто.
  • Карточки суб-агентов в чате: только Claude Code.
  • Повторное внедрение памяти, когда агент сжимает свой контекст: только Claude и Pi.
  • Собственные агенты: только те, что поддерживают ACP.
  • Голосовая диктовка: только на испанском, а её работа в упакованной версии ещё не проверена.
  • Интерфейс на 11 языках: испанский и английский полные; в остальных могут встречаться непереведённые тексты.
  • Telegram: только пока Devia открыт, с одним авторизованным чатом и без интерактивных карточек.

Чего пока не умеет

  • Создавать коммиты, делать push или открывать pull request из интерфейса.
  • Использовать GitHub, GitLab, Linear или Jira как источник задач.
  • Встроенный редактор файлов: дерево проекта только для чтения, а файлы открываются в вашей IDE.
  • Координатор, который запускает и контролирует нескольких агентов-исполнителей. Сейчас параллелизм обеспечивает разделённый вид, которым управляете вы.
  • Автоматизации по расписанию или по событиям.
  • Работа на удалённых серверах по SSH, в облаке или без графического интерфейса.
  • Нативное мобильное приложение: телефон используется через Telegram.
  • Система плагинов для сторонних панелей или тем.
  • Управление компьютером, мобильные эмуляторы или встроенный браузер.

Настройка и данные

Почти вся информация Devia хранится на вашем диске, в ~/.devia-app/ (в Windows это C:\Users\<ваш-пользователь>\.devia-app\):

ПутьСодержимое
devia-app.config.jsonКонфигурация: workspace, активный агент, язык и т. д. (секреты, такие как токен Telegram, хранятся в зашифрованном виде)
sessions/<проект>/История чата по проектам
projects/<ключ>/Данные проекта: доска Kanban (kanban.json) и память (memory.json)
memory-global.jsonЛичная память
mcp-servers.jsonНастроенные MCP-серверы
snapshots/Снимки конфигурации перед её изменением
worktrees/Git worktrees дополнительных панелей разделённого вида
attachments/Файлы, прикреплённые в поле ввода или через Telegram
outbox-archive/Файлы, созданные агентом

Чтобы сделать резервную копию Devia, достаточно скопировать эту папку. Её удаление возвращает приложение в исходное состояние. Журнал аудита tool-call хранится отдельно, в папке пользовательских данных приложения.

Обновления

Опубликованные версии объявляются в публичном манифесте этого сайта: updates/latest.json. Он содержит последнюю доступную версию, дату публикации, примечания и ссылки на загрузку для каждой платформы.

Установки Devia Desktop обновляются сами из Releases репозитория (на Linux только для AppImage). Последнюю версию можно также проверить вручную или из своих скриптов:

curl -s https://dherrero.github.io/devia/updates/latest.json | jq .version

Часто задаваемые вопросы

Devia бесплатен?

Да. Devia Desktop имеет открытый код (Apache-2.0), со всеми функциями, на всех платформах.

Нужна ли учётная запись или подключение к какому-либо сервису Devia?

Нет. Devia Desktop работает локально. Единственные внешние сервисы, которые используются, это сервисы самих CLI-агентов, настроенных у вас.

Включает ли Devia ИИ-агентов?

Нет: Devia это интерфейс, который ими управляет. Вам нужен хотя бы один установленный агентный CLI (Claude Code, Codex, Gemini CLI, OpenCode…) с вашими учётными данными. Devia их обнаружит и возьмёт на себя остальное.

Покидают ли мои данные мою машину?

Сессии, память, kanban и конфигурация хранятся в ~/.devia-app/. Голосовая диктовка тоже выполняется локально. Передаётся только то, что CLI используемого вами агента отправляет своему провайдеру.

На каких языках доступно приложение?

Этот сайт доступен на испанском, английском, валенсийском, французском, немецком, итальянском, португальском, русском, китайском, хинди и арабском. В приложении те же 11 языков, но полностью переведены только испанский и английский: в остальных могут встречаться непереведённые тексты.

Можно ли управлять им с телефона?

Да, через Telegram, при условии, что Devia открыт на вашем компьютере. Нативного мобильного приложения нет.

Как сообщить о проблеме?

Создайте обращение в репозитории Devia на GitHub, указав шаги для воспроизведения и вашу платформу (Windows/macOS/Linux).
