Документация Devia Desktop

Что такое Devia Desktop?

Devia Desktop — это десктопное приложение для разработки программного обеспечения с ИИ-агентами. Удобный единый интерфейс над несколькими агентными CLI-инструментами (Claude Code, Codex, Gemini CLI и другими), превращающий работу с агентами в терминале в визуальный, организованный и многопроектный опыт.

Это FreeWare: бесплатно со 100% возможностей, доступно для Windows, macOS и Linux. Всё работает локально, с вашими проектами и вашими CLI — учётная запись и подключение к каким-либо сторонним сервисам не требуются.

Установка

Windows

  1. Скачайте установщик .exe со страницы загрузок.
  2. Запустите его и выберите папку для установки (установка для пользователя, без прав администратора).
  3. Если SmartScreen покажет предупреждение, нажмите «Подробнее → Выполнить в любом случае».

macOS

  1. Скачайте .dmg для вашей архитектуры (Apple Silicon или Intel).
  2. Откройте его и перетащите Devia в папку Программы.
  3. Приложение подписано и нотаризовано Apple: открывается без дополнительных шагов.

Linux

  1. AppImage: скачайте, дайте права на выполнение командой chmod +x Devia-*.AppImage и запустите.
  2. Debian/Ubuntu: установите пакет командой sudo dpkg -i devia_*_amd64.deb.

Первые шаги

  1. Выберите workspace. При первом запуске Devia откроется модальное окно с запросом корневой папки, в которой находятся ваши проекты (например ~/repos). Devia выведет список содержащихся в ней проектов и определит их технологию.
  2. Подключите агента. Devia обнаружит агентные CLI, установленные на вашей машине, и позволит вам выбрать активного агента в Настройках. Каждый проект будет настроен так, чтобы агент работал без ручной конфигурации.
  3. Общайтесь. Откройте проект и введите первую инструкцию в поле ввода. Выберите режим выполнения — plan (только планирование), apply (применение с подтверждением) или apply-yolo (без подтверждений) — в зависимости от того, сколько автономии вы хотите предоставить агенту.
  4. Проверяйте. Каждый ответ поступает в потоковом режиме с markdown, вызовы инструментов раскрываются в карточках, а изменения агента отображаются как инлайн-диффы.

Поддерживаемые агенты

Devia работает со следующими CLI-инструментами для написания кода, между которыми можно переключаться, не выходя из приложения:

АгентПримечания
Claude CodeПолная интеграция, включая MCP-серверы на уровне сессии
OpenAI CodexПотоковая передача JSON-событий
Gemini CLIПотоковая передача JSON-событий
OpenCodeПотоковая передача JSON-событий
Cursor AgentПотоковая передача JSON-событий
GitHub Copilot CLIПотоковая передача JSON-событий
Qwen · DeepSeek · QoderВывод в виде простого текста

При продолжении сессии с агентом, отличным от того, который её начал, Devia выполняет автоматическую передачу контекста: в первый ход нового агента внедряется сводка проделанной работы (цель, затронутые файлы и последние обмены), а в чате появляется разделитель.

Возможности

Мультипроект и сессии

  • Список, создание (пустого или из шаблона) и клонирование проектов; закрепление избранного на боковой панели.
  • История сессий по проектам, сохраняющаяся между перезапусками; продолжение или перезапуск сессии одним нажатием.
  • Очередь инструкций: добавляйте промпты, пока агент занят, переупорядочивайте перетаскиванием, ставьте на паузу и возобновляйте.

Разделённый вид мультисессии

  • До 4 панелей (2×2) в одном окне, каждая со своей сессией и агентом, работающим параллельно.
  • Каждая дополнительная панель работает изолированно в собственном git worktree (новая ветка от основной), чтобы два агента никогда не вносили изменения в одни и те же файлы.
  • Разделение и его worktrees сохраняются после перезапуска приложения, восстанавливая файлы каждой сессии.

Kanban со встроенным SDD

  • Kanban-доска для каждого проекта со спецификациями, задачами и зависимостями.
  • Сам агент читает и обновляет доску через MCP (devia-kanban): процесс spec-driven development от начала до конца.
  • Состояние хранится за пределами репозитория, в папке данных Devia.

Постоянная память

  • Собственная память между сессиями (devia-memory) с личной областью и областью проекта.
  • Агент обращается к ней и пополняет её автоматически: решения, исправленные баги и открытия фиксируются.
  • Панель управления в Настройках: ищите, закрепляйте, удаляйте или очищайте наблюдения.

Встроенный Git

  • Состояние репозитория в реальном времени на боковой панели.
  • Просмотр изменений с построчными комментариями: аннотируйте строки диффа и отправляйте их агенту как запрос на ревью.
  • Поддержка worktrees и снимков состояния с откатом перед деструктивными операциями.

MCP-серверы, skills и промпты

  • Менеджер серверов Model Context Protocol: устанавливайте, включайте, тестируйте и используйте серверы совместно между агентами; Devia внедряет конфигурацию в нативный формат каждого CLI.
  • Находите и устанавливайте skills локально или из GitHub.
  • Prompt packs: наборы системных промптов для каждого проекта.
  • Менеджер повторно используемых мульти-CLI суб-агентов между проектами.

Удалённое управление через Telegram

  • Запускайте задачи, проверяйте статус (ветка, использованный контекст, стоимость) и общайтесь с агентом из Telegram.
  • Опциональное зеркалирование десктопного разговора и отправка вложений (фото, документы) агенту.

Терминал, голос и многое другое

  • Встроенный терминал для каждого проекта с настоящим PTY и открытие проекта в вашей любимой IDE.
  • Оркестрация Docker Compose: deploy, down и логи для каждого проекта.
  • Локальная транскрипция голоса с Whisper — аудио никогда не покидает вашу машину.
  • Прикрепление изображений перетаскиванием для мультимодальных моделей.
  • Файловый браузер проекта на правой панели и архив файлов, сгенерированных агентом (outbox).
  • Журнал аудита каждого tool-call с ротацией и хранением в течение 30 дней.
  • 11 языков (es, en, ca, fr, de, it, pt, ru, zh, hi, ar), 8 цветовых акцентов Material 3 и настраиваемый размер шрифта.

Настройка и данные

Все данные Devia хранятся на вашем диске в папке ~/.devia-app/ (в Windows — C:\Users\<tu-usuario>\.devia-app\):

ПутьСодержимое
devia-app.config.jsonНастройки: workspace, активный агент, тема, язык…
sessions/<proyecto>/История чата по проектам
projects/<clave>/kanban.jsonKanban-доска проекта
memory-global.json · projects/<clave>/memory.jsonПостоянная память (личная · по проекту)
mcp-servers.jsonНастроенные MCP-серверы
outbox-archive/Файлы, сгенерированные агентом
attachments/Изображения, прикреплённые в поле ввода
audit.logЖурнал tool-call'ов (JSONL с ротацией)

Для резервного копирования Devia достаточно скопировать эту папку. Её удаление вернёт приложение к исходному состоянию.

Обновления

Опубликованные версии анонсируются в публичном манифесте этого сайта: updates/latest.json. Он содержит последнюю доступную версию, дату публикации, примечания и ссылки для скачивания по платформам.

Devia Desktop обращается к этому манифесту, чтобы уведомить вас о выходе новой версии. Вы также можете проверить это вручную или из своих скриптов:

curl -s https://dherrero.github.io/devia/updates/latest.json | jq .version

Часто задаваемые вопросы

Devia бесплатна?

Да. Devia Desktop — FreeWare со 100% возможностей на всех платформах.

Нужны ли мне учётная запись или подключение к какому-либо сервису Devia?

Нет. Devia Desktop работает полностью локально. Единственные внешние сервисы — это те, которые использует настроенный вами агентный CLI.

Devia включает ИИ-агентов?

Нет: Devia — это интерфейс для управления ими. Вам необходимо установить хотя бы один агентный CLI (Claude Code, Codex, Gemini CLI, OpenCode…) с вашими учётными данными. Devia обнаружит их и возьмёт всё остальное на себя.

Мои данные покидают мою машину?

Нет. Сессии, память, kanban и настройки хранятся в ~/.devia-app/. Транскрипция голоса с Whisper также выполняется локально. В сеть уходит только то, что отправляет используемый вами агентный CLI своему провайдеру.

На каких языках доступно приложение?

Испанский, английский, валенсийский, французский, немецкий, итальянский, португальский, русский, китайский, хинди и арабский.

Как сообщить о проблеме?

Откройте issue в репозитории Devia на GitHub, описав шаги для воспроизведения и вашу платформу (Windows/macOS/Linux).
