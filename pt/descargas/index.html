Atualizações

O Devia Desktop verifica novas versões a partir do manifesto público deste site: updates/latest.json. Podes consultá-lo manualmente ou integrá-lo nos teus próprios scripts.

Requisitos

  • Pelo menos um agente CLI de codificação instalado: Claude Code, OpenAI Codex, Gemini CLI, OpenCode, Cursor Agent, GitHub Copilot CLI, Qwen, DeepSeek ou Qoder. O Devia deteta-os automaticamente.
  • Git instalado (recomendado) para o estado do repositório, os diffs e os worktrees da vista dividida.
  • Docker (opcional) para a orquestração de Docker Compose por projeto.
