Devia Desktop क्या करता है?

🤖 Multi-agent

Claude Code, OpenAI Codex, Gemini CLI, OpenCode, Cursor Agent, GitHub Copilot CLI, Qwen, DeepSeek या Qoder के साथ काम करें और tool बदले बिना agent बदलें। Devia इंस्टॉल किए गए CLIs को detect करता है और हर project को बिना manual सेटअप के काम करने के लिए configure करता है।

💬 Agent पर Visual Chat

Streaming responses, markdown, collapsible tool calls, diff viewer और multimodal models के लिए image attachments।

🪟 Multi-project और Multi-session

Project-wise session history, instruction queue और 4 panels (2×2) तक का split view — हर panel में अपना session और git worktree — एक ही window में कई agents समानांतर में काम करते हैं।

📋 Integrated SDD के साथ Kanban

Project-wise board जिसे agent खुद MCP (devia-kanban) के ज़रिए पढ़ता और अपडेट करता है, specs, tasks, dependencies और spec-driven development flow के साथ।

🧠 Persistent Memory

Devia में sessions के बीच अपनी memory (devia-memory) है — personal और project-level scope के साथ — जिसे agent स्वतः query और update करता है।

🌿 Integrated Git

Live repository status, inline comments के साथ diff viewer जिससे agent से review माँगा जा सके, और worktrees का support।

🔌 MCP Server Manager

MCP servers install, activate और agents के बीच share करें; Devia हर CLI के native format में configuration inject करता है।

✨ Skills और Prompt Packs

Skills discover और install करें (locally या GitHub से) और हर project के लिए system prompt packages define करें।

📱 Telegram से Remote Control

Telegram से runs launch करें, status check करें और agent से बात करें — desktop conversation का optional mirror भी।

🖥️ Terminal और Shell

Project-wise integrated terminal (real PTY), अपने पसंदीदा IDE में खोलने का विकल्प और Docker Compose orchestration।

🎙️ Voice

Whisper के साथ local transcription — audio किसी भी API को नहीं भेजा जाता।

🛡️ Snapshots और Auditing

Destructive operations से पहले snapshots और rollback, और हर tool-call का audit log जिसमें automatic rotation और retention हो।

Local में काम करने के लिए बनाया गया

Devia Desktop आपके projects और CLIs के साथ, आपकी machine पर काम करता है। आपके sessions, memory, kanban और configuration आपकी disk पर रहते हैं (~/.devia-app/)। कोई account नहीं, कोई cloud नहीं, कोई telemetry नहीं: install करें, अपना work folder चुनें और agents को direct करना शुरू करें।

1 · Install करें

अपने platform का installer डाउनलोड करें और खोलें। किसी prior configuration की ज़रूरत नहीं।

2 · Agents कनेक्ट करें

Devia आपके पहले से इंस्टॉल किए गए coding CLIs (Claude Code, Codex, Gemini CLI…) को detect करता है और उन्हें use के लिए तैयार कर देता है।

3 · Direct करें

अपने workspace का कोई project खोलें और बात करें: agent code करता है, आप diffs review करते हैं, approve करते हैं और अगली instructions queue में डालते हैं।
