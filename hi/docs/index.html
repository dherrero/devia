Devia Desktop दस्तावेज़ीकरण

Devia Desktop क्या है?

Devia Desktop AI agents के साथ सॉफ़्टवेयर विकसित करने के लिए एक डेस्कटॉप ऐप है। यह कई agentic CLIs (Claude Code, Codex, Gemini CLI और अन्य) पर एक एकीकृत इंटरफ़ेस है, जो terminal में agents के साथ काम करने को एक visual, व्यवस्थित और multi-project अनुभव में बदल देता है।

यह ओपन सोर्स (Apache-2.0) है: मुफ़्त, सभी सुविधाओं के साथ, Windows, macOS और Linux के लिए उपलब्ध। सब कुछ आपकी मशीन पर, आपके प्रोजेक्ट्स और आपके CLIs के साथ चलता है; इसे Devia की किसी सेवा के खाते या कनेक्शन की ज़रूरत नहीं है।

इंस्टॉलेशन

Windows

  1. डाउनलोड पेज से .exe इंस्टॉलर डाउनलोड करें।
  2. उसे चलाएँ और इंस्टॉलेशन डायरेक्टरी चुनें (प्रति-उपयोगकर्ता इंस्टॉलेशन, administrator अनुमति के बिना)।
  3. अगर SmartScreen चेतावनी दिखाए, तो “More info → Run anyway” दबाएँ।

macOS

  1. अपने आर्किटेक्चर (Apple Silicon या Intel) का .dmg डाउनलोड करें।
  2. उसे खोलें और Devia को Applications फ़ोल्डर में खींचें।
  3. ऐप Apple द्वारा साइन और notarize की गई है: यह बिना किसी अतिरिक्त चरण के खुलती है।

Linux

  1. AppImage: उसे डाउनलोड करें, chmod +x Devia-*.AppImage से अनुमति दें और चलाएँ।
  2. Debian/Ubuntu: sudo dpkg -i devia_*_amd64.deb से पैकेज इंस्टॉल करें।

शुरुआत कैसे करें

  1. अपना workspace चुनें। Devia पहली बार खोलने पर एक modal आपसे वह रूट फ़ोल्डर पूछता है जहाँ आपके प्रोजेक्ट्स रहते हैं (जैसे ~/repos)। Devia उसमें मौजूद प्रोजेक्ट्स की सूची बनाता है और उनकी तकनीक पहचानता है।
  2. एक agent जोड़ें। Devia आपकी मशीन पर इंस्टॉल किए गए agentic CLIs को पहचानता है और आपको सेटिंग्स में सक्रिय agent चुनने देता है। हर प्रोजेक्ट इस तरह कॉन्फ़िगर होता है कि agent बिना manual सेटअप के काम करे।
  3. बातचीत करें। कोई प्रोजेक्ट खोलें और composer में अपना पहला निर्देश लिखें। निष्पादन मोड चुनें: plan (केवल योजना बनाता है), apply (अनुमतियों के साथ लागू करता है) या apply-yolo (बिना पुष्टि के), इस पर निर्भर करते हुए कि आप कितनी स्वायत्तता देना चाहते हैं।
  4. समीक्षा करें। हर उत्तर markdown के साथ streaming में आता है, tool calls कार्डों में खुलते हैं और agent के बदलाव inline diffs के रूप में दिखते हैं।

समर्थित agents

Devia नीचे दिए गए coding CLIs को चलाता है और आप ऐप छोड़े बिना एक से दूसरे पर जा सकते हैं। एकीकरण का स्तर agent के अनुसार बदलता है:

Agentएकीकरण
Claude Codeसबसे पूर्ण: हर run के लिए MCP servers, चैट में sub-agent कार्ड और उपयोग सीमा के बाद स्वचालित रूप से फिर शुरू होना।
OpenCodeसमर्पित एकीकरण।
Piसमर्पित एकीकरण।
Kimi और HermesAgent Client Protocol (ACP) के ज़रिए। Kimi की प्रोफ़ाइल अभी असली CLI के विरुद्ध सत्यापित नहीं है।
Codex, Gemini CLI, Cursor Agent, GitHub Copilot CLI, Grok, Qwen, Qoder और DeepSeekहर CLI की streaming पर आधारित सामान्य एकीकरण।
आपका अपना agentACP बोलने वाले किसी भी CLI को agent-defs.json में परिभाषित किया जा सकता है।

जब कोई सत्र उस agent से अलग agent के साथ जारी रखा जाता है जिसने उसे शुरू किया था, तो Devia context हैंडऑफ़ करता है: वह काम का सारांश (लक्ष्य, छुई गई फ़ाइलें और हाल का आदान-प्रदान) नए agent के पहले turn में डालता है और चैट में एक विभाजक छोड़ता है। AI से बने सारांश के लिए Claude और ANTHROPIC_API_KEY ज़रूरी हैं।

Devia क्या-क्या कर सकता है

Agents और निष्पादन

  • plan, apply और apply-yolo मोड हर सत्र के साथ सहेजे जाते हैं। वे कैसे लागू होते हैं यह agent पर निर्भर करता है: जैसे Codex में plan मोड prompt के निर्देशों पर टिका है।
  • Claude Code, Codex और Grok के मौजूदा सत्र import करें और Devia में जारी रखें।
  • Claude Code के साथ, उपयोग सीमा के बाद Devia सत्र अपने आप फिर शुरू करता है, बशर्ते ऐप खुला रहे।
  • हर सत्र का उपयोग हुआ context, लागत, tokens और compactions, स्थानीय रूप से गणना किए गए।
  • प्रोजेक्ट-वार निर्देशों की कतार: agent के काम करते समय prompts कतार में रखें, drag and drop से क्रम बदलें, रोकें और फिर शुरू करें।
  • Claude Code के sub-agents की calls चैट में नेस्टेड दिखती हैं।

Multi-project और split view

  • प्रोजेक्ट्स की सूची, निर्माण (खाली या template से) और clone; पसंदीदा साइडबार में पिन किए जा सकते हैं।
  • प्रोजेक्ट-वार सत्र इतिहास, जो रीस्टार्ट के बाद भी बना रहता है।
  • एक ही विंडो में 4 तक panels (2×2), हर एक का अपना सत्र और अपना agent, समानांतर काम करते हुए।
  • हर अतिरिक्त panel अपने git worktree में अलग काम करता है, ताकि दो agents कभी एक ही फ़ाइलों को न छुएँ।

Context और memory

  • सत्रों के बीच स्थायी memory (devia-memory), निजी और प्रोजेक्ट-वार, वैकल्पिक semantic पुनःक्रमण के साथ। agent उससे पूछता है और उसे भरता है; आप उसे सेटिंग्स में प्रबंधित करते हैं।
  • अपना code graph (6 भाषाएँ) जिसे agents MCP से query करते हैं, और उसे देखने के लिए एक /graph view।
  • Code mode: agent एक TypeScript script लिखता है जो आपके चुने MCP servers पर sandbox में चलती है और केवल परिणाम लौटाती है। इस संस्करण में scripts केवल पढ़ती हैं।

Method और योजना

  • प्रोजेक्ट-वार kanban, specs, tasks और dependencies के साथ, जिसे agent MCP (devia-kanban) से पढ़ता और अपडेट करता है। स्थिति रिपॉज़िटरी के बाहर रहती है।
  • Devia Method: विकास की अपनी पद्धति (skills और शुरुआती prompt) जिसे Devia सभी agents को देता है, और जो प्रोजेक्ट-वार सक्रिय की जा सकती है।
  • किसी भी agent के लिए इंटरैक्टिव कार्ड: सवाल, plans की मंज़ूरी, बदलावों की समीक्षा, पुष्टियाँ और चयन। केवल desktop पर।
  • skills का प्रबंधक (स्थानीय या GitHub से) और दोबारा इस्तेमाल होने वाले sub-agents का प्रबंधक, जिन्हें Devia हर CLI के साथ sync करता है।

Git और समीक्षा

  • रिपॉज़िटरी की live स्थिति, inline diff viewer, branch चयनकर्ता और केवल fast-forward pull।
  • diff पर पंक्ति-वार टिप्पणियाँ, जो समीक्षा के अनुरोध के रूप में agent को भेजी जाती हैं।
  • MCP, skills और sub-agents के कॉन्फ़िगरेशन को बदलने से पहले उसके snapshots, restore की सुविधा के साथ।
  • commits, push और pull requests agent अपने औज़ारों से करता है: Devia उन्हें खुद नहीं बनाता।

MCP servers

  • Model Context Protocol servers का प्रबंधक, शुरुआती catalog के साथ: servers इंस्टॉल करें, सक्रिय करें और जाँचें। Devia कॉन्फ़िगरेशन 9 agents के native format में लिखता है।
  • हर server को agent को सीधे या code mode के ज़रिए दिया जा सकता है।

Telegram से रिमोट कंट्रोल

  • Telegram से runs शुरू करें, मोड या agent बदलें, स्थिति (branch, उपयोग हुआ context, लागत) देखें और agent से बातचीत करें।
  • agent को अटैचमेंट भेजें और उसकी बनाई फ़ाइलें पाएँ। desktop बातचीत का वैकल्पिक mirror।
  • यह केवल तब चलता है जब Devia खुला हो और एक ही अधिकृत चैट को सेवा देता है। इंटरैक्टिव कार्ड Telegram में नहीं दिखते: agent टेक्स्ट में पूछता है।

Terminal, आवाज़ और बहुत कुछ

  • प्रोजेक्ट-वार इंटीग्रेटेड terminal असली PTY के साथ, और प्रोजेक्ट को 10 IDEs में खोलने की सुविधा।
  • Docker Compose ऑर्केस्ट्रेशन: प्रोजेक्ट-वार deploy, down और logs।
  • किसी भी प्रकार के अटैचमेंट (प्रति फ़ाइल 50 MB तक) और agent की बनाई फ़ाइलों का archive।
  • स्थानीय voice dictation; आज केवल स्पेनिश में।
  • हर tool-call का audit log।
  • इंस्टॉलेशन का स्वचालित अपडेट (Linux पर केवल AppImage के साथ)।

क्षमताएँ और सीमाएँ

Devia आज क्या करता है और अभी क्या नहीं करता, इसका ईमानदार सार, ताकि आप जान सकें कि क्या उम्मीद रखें।

जो यह करता है

  • एक विंडो से 13 agentic CLIs चलाना, plan, apply और apply-yolo मोड के साथ।
  • अलग-अलग git worktrees के साथ 4 panels तक का split view।
  • kanban, memory, code graph और code mode, जो agent को MCP से उपलब्ध हैं।
  • MCP, skills और sub-agents के प्रबंधक।
  • सवाल पूछने, plans मंज़ूर करने और बदलाव जाँचने के लिए इंटरैक्टिव कार्ड।
  • agent को भेजी गई पंक्ति-वार समीक्षा टिप्पणियाँ।
  • Telegram से रिमोट कंट्रोल, फ़ाइलें भेजने के साथ।
  • Terminal, Docker Compose और IDEs में खोलना।

जो यह आंशिक रूप से करता है

  • सत्र import करना: केवल Claude Code, Codex और Grok से।
  • उपयोग सीमा के बाद फिर शुरू होना: केवल Claude Code, और केवल जब तक ऐप खुला रहे।
  • चैट में sub-agent कार्ड: केवल Claude Code।
  • agent के अपना context compact करने पर memory दोबारा डालना: केवल Claude और Pi।
  • अपने agents: केवल वे जो ACP बोलते हैं।
  • Voice dictation: केवल स्पेनिश में, और पैकेज्ड संस्करण में उसका काम करना अभी सत्यापित होना बाकी है।
  • 11 भाषाओं में इंटरफ़ेस: स्पेनिश और अंग्रेज़ी पूर्ण हैं; बाकी में कुछ टेक्स्ट अनुवादित न हों।
  • Telegram: केवल जब Devia खुला हो, एक ही अधिकृत चैट के साथ, और इंटरैक्टिव कार्ड के बिना।

जो यह अभी नहीं करता

  • इंटरफ़ेस से commits बनाना, push करना या pull requests खोलना।
  • GitHub, GitLab, Linear या Jira को tasks के स्रोत के रूप में इस्तेमाल करना।
  • इंटीग्रेटेड फ़ाइल editor: प्रोजेक्ट ट्री केवल पढ़ने के लिए है और फ़ाइलें आपके IDE में खुलती हैं।
  • एक coordinator जो कई worker agents को शुरू करे और उनकी निगरानी करे। आज समानांतरता split view है, जिसे आप खुद चलाते हैं।
  • समय-निर्धारित या events से शुरू होने वाले automations।
  • SSH से, क्लाउड में या बिना ग्राफ़िकल इंटरफ़ेस के remote servers पर चलाना।
  • एक native मोबाइल ऐप: मोबाइल का उपयोग Telegram के ज़रिए होता है।
  • तीसरे पक्ष के panels या themes के लिए plugins की प्रणाली।
  • कंप्यूटर का नियंत्रण, मोबाइल emulators या इंटीग्रेटेड browser।

कॉन्फ़िगरेशन और डेटा

Devia की लगभग सारी जानकारी आपकी डिस्क पर ~/.devia-app/ के नीचे रहती है (Windows पर C:\Users\<tu-usuario>\.devia-app\):

पथसामग्री
devia-app.config.jsonकॉन्फ़िगरेशन: workspace, सक्रिय agent, भाषा आदि (Telegram token जैसे secrets एन्क्रिप्टेड सहेजे जाते हैं)
sessions/<proyecto>/प्रोजेक्ट-वार चैट इतिहास
projects/<clave>/प्रोजेक्ट-वार डेटा: Kanban बोर्ड (kanban.json) और memory (memory.json)
memory-global.jsonनिजी memory
mcp-servers.jsonकॉन्फ़िगर किए गए MCP servers
snapshots/कॉन्फ़िगरेशन बदलने से पहले के snapshots
worktrees/split view के अतिरिक्त panels के git worktrees
attachments/composer में या Telegram से जोड़ी गई फ़ाइलें
outbox-archive/agent की बनाई फ़ाइलें

अपने Devia का बैकअप लेने के लिए उस फ़ोल्डर की कॉपी बना लेना काफ़ी है। उसे हटाने से ऐप अपनी शुरुआती स्थिति में लौट आता है। tool-calls का audit log अलग से, ऐप के user data फ़ोल्डर में सहेजा जाता है।

अपडेट

प्रकाशित संस्करणों की घोषणा इस साइट के सार्वजनिक manifest में होती है: updates/latest.json। उसमें नवीनतम उपलब्ध संस्करण, प्रकाशन तिथि, नोट्स और प्लेटफ़ॉर्म-वार डाउनलोड लिंक होते हैं।

Devia Desktop के इंस्टॉलेशन रिपॉज़िटरी की Releases से अपने आप अपडेट होते हैं (Linux पर केवल AppImage के साथ)। आप नवीनतम संस्करण हाथ से या अपनी scripts से भी देख सकते हैं:

curl -s https://dherrero.github.io/devia/updates/latest.json | jq .version

अक्सर पूछे जाने वाले प्रश्न

क्या Devia मुफ़्त है?

हाँ। Devia Desktop ओपन सोर्स (Apache-2.0) है, सभी सुविधाओं के साथ, सभी प्लेटफ़ॉर्म पर।

क्या मुझे Devia की किसी सेवा के खाते या कनेक्शन की ज़रूरत है?

नहीं। Devia Desktop आपकी मशीन पर चलता है। केवल वही बाहरी सेवाएँ इस्तेमाल होती हैं जो आपके कॉन्फ़िगर किए agent CLIs की अपनी हैं।

क्या Devia में AI agents शामिल हैं?

नहीं: Devia वह इंटरफ़ेस है जो उन्हें चलाता है। आपके पास कम से कम एक agentic CLI (Claude Code, Codex, Gemini CLI, OpenCode…) अपने credentials के साथ इंस्टॉल होना चाहिए। Devia उन्हें पहचानता है और बाकी सँभालता है।

क्या मेरा डेटा मेरी मशीन से बाहर जाता है?

सत्र, memory, kanban और कॉन्फ़िगरेशन ~/.devia-app/ में रहते हैं। voice dictation भी स्थानीय रूप से चलता है। केवल वही बाहर जाता है जो आपका इस्तेमाल किया हुआ agent CLI अपने प्रदाता को भेजता है।

यह किन भाषाओं में उपलब्ध है?

यह वेबसाइट स्पेनिश, अंग्रेज़ी, वैलेंसियन, फ़्रेंच, जर्मन, इतालवी, पुर्तगाली, रूसी, चीनी, हिन्दी और अरबी में है। ऐप में यही 11 भाषाएँ हैं, लेकिन केवल स्पेनिश और अंग्रेज़ी पूर्ण हैं: बाकी में कुछ टेक्स्ट अनुवादित न दिखें।

क्या मैं इसे मोबाइल से नियंत्रित कर सकता हूँ?

हाँ, Telegram के ज़रिए, बशर्ते आपके कंप्यूटर पर Devia खुला हो। कोई native मोबाइल ऐप नहीं है।

मैं किसी समस्या की रिपोर्ट कैसे करूँ?

Devia के GitHub रिपॉज़िटरी में एक issue खोलें, जिसमें उसे दोहराने के चरण और आपका प्लेटफ़ॉर्म (Windows/macOS/Linux) हो।
