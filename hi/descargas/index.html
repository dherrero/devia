Updates

Devia Desktop इस site के public manifest के विरुद्ध नए versions check करता है: updates/latest.json। आप इसे manually check कर सकते हैं या अपने scripts में integrate कर सकते हैं।

ज़रूरतें

  • कम से कम एक coding CLI agent install हो: Claude Code, OpenAI Codex, Gemini CLI, OpenCode, Cursor Agent, GitHub Copilot CLI, Qwen, DeepSeek या Qoder। Devia इन्हें automatically detect करता है।
  • Repository status, diffs और split view के worktrees के लिए Git install हो (recommended)।
  • Project-wise Docker Compose orchestration के लिए Docker (optional)।
